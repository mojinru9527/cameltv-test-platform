# 历史缺陷模式摘要（运行时注入，请按覆盖判定使用）

> 规则：strong=只关联不新增；partial=增强原用例；none=确属缺口才新增一条最小用例；不适用则跳过并说明。
> 通用经验非项目历史 Bug，标 GENERIC-RISK。不得编造 Bug ID。

| Pattern | 失效模式 | 哪里测 | 怎样触发 | 看什么断言 | 覆盖 | 动作 |
|---|---|---|---|---|---|---|
| CAMEL-BP-001 | 重复触发未防抖导致重复页面/重复业务结果 | 列表行点击进入详情；提交/保存按钮点击态 | 对同一目标 300ms 内连续点击 2 次以上；弱网下先点击后重试 | 只打开 1 个详情页（页面栈深度 +1）；只生成 1 条记录（DB count +1） | partial | enhance-existing |
| CAMEL-BP-002 | 同一字段在不同入口的长度/格式校验不一致 | 新增/编辑表单提交；生成娃娃名称输入框 | 在 A 入口输入 N 字通过，再到 B 入口输入 N 字；在名称字段粘贴超过上限的字符 | 两个入口最大长度一致并显示剩余字数；超长即时提示且不提交、不报 500 | none | add-minimal-case |
| CAMEL-BP-003 | 超长/纯数字文本溢出、不换行、截断与遮挡 | 评论列表；系统消息列表与详情弹窗 | 发布纯数字或连续英文评论（长度≥30）；推送标题>2 行、内容>3 行 | 文本在容器内换行或按规则省略，无横向滚动/溢出；标题≤2 行、内容≤3 行且可展开 | partial | enhance-existing |
| CAMEL-BP-004 | 抽屉/弹窗关闭后状态残留导致页面失效 | 列表页抽屉关闭后；退出登录返回登录页后 | 打开抽屉→点击关闭/ESC→立刻点击列表其他按钮；连续打开再关闭 2 次抽屉 | 关闭后遮罩消失、body 可滚动、列表按钮可点；再次打开抽屉内容正常 | none | add-minimal-case |
| CAMEL-BP-005 | 搜索/筛选后行操作无响应或结果集不完整 | 列表搜索框；组合筛选条件 | 输入关键词→搜索→点击首行【查看】；组合两个以上筛选条件→翻页→查看 | 搜索结果 total 与命中条数一致且含全部匹配项；行操作立即响应并打开正确对象 | partial | enhance-existing |
| CAMEL-BP-006 | 异步生成/渲染任务无进度、超时或结果不可重拉 | 一键换装按钮 pending 态；精修任务列表 | 弱网下触发换装/精修任务；任务进行中刷新页面 | 有明确进行中/成功/失败态与失败原因；超时后可重试且不重复创建 | none | add-minimal-case |
| CAMEL-BP-007 | 不应出现的操作入口仍展示（关注/删除/购买） | 帖子详情操作区；我的作品列表项操作菜单 | 匿名发帖后由他人查看；匿名发布作品后进入我的作品 | 匿名帖无关注按钮；匿名作品有删除入口且能删除；不可购买商品给出换一件引导，不重复生成名字/性格 | partial | enhance-existing |
| CAMEL-BP-008 | 空态/缺省资源无兜底（无图无头像占位文案） | 个人信息页；社区列表卡片封面 | 新用户未填生日/地区；发布纯文字帖子 | 无数据显示占位文案（如「未设置」）而非控件名；无图帖显示平台兜底 icon | partial | enhance-existing |
| CAMEL-BP-009 | 时间/时区展示漂移（相对时间错误） | 系统消息列表时间；消息详情弹窗时间 | 推送后立即打开消息详情弹窗；设备时区非 UTC+8 或跨零点 | 弹窗时间与列表/推送时间差 <1 分钟且时区为本地；跨天显示日期不显示错误相对时间 | none | add-minimal-case |
| CAMEL-BP-010 | 图片上传无尺寸约束导致展示裁切 | 后台上传控件提示文案；社区列表与详情图 | 上传 1:1 / 3:4 / 超宽图各一张；上传超分辨率大图 | 上传前显示推荐尺寸/比例与大小上限；前台按比例完整展示或明确裁切规则 | none | add-minimal-case |
| CAMEL-BP-011 | 地址/文本解析规则缺失（直辖市与重名市区） | 收货地址识别/解析；订单地址展示 | 输入「北京市朝阳区…」；输入「吉林省吉林市…」 | 省市区三级解析正确且与行政区划一致；直辖市按省市级处理 | partial | enhance-existing |
| CAMEL-BP-012 | 首次登录资料缺失导致主流程中断 | 登录成功跳转；评论输入框提交 | 全新用户首次授权登录后立即评论；清除资料后再次评论 | 登录后自动带入微信头像昵称或弹出一次就地补全；补全后评论可继续且不丢草稿 | partial | enhance-existing |
| CAMEL-BP-013 | 保存/草稿动作未触发或状态不持久 | 发帖页草稿按钮；草稿箱列表 | 编辑内容后点存草稿；存草稿后退出重进 | 点击后有成功 toast 且草稿箱新增 1 条；重进可续编且内容一致 | strong | skip |
| CAMEL-BP-014 | 社交关系数据不可查看/计数不一致 | 我的页面社交入口；关注/粉丝列表 | 进入我的→关注/粉丝；点赞后刷新列表 | 关注/粉丝列表可打开并与计数一致；点赞/收藏后计数 +1 且刷新后保持 | partial | enhance-existing |
| CAMEL-BP-015 | 退出登录/页面切换资源加载慢导致黑屏 | 退出登录跳转；登录页背景渲染 | 冷缓存下点击退出登录；弱网（3G）下退出/刷新 | 退出后 1s 内出现登录页内容，无纯黑/纯白屏；背景图有占位或渐变兜底 | none | add-minimal-case |
| CAMEL-BP-016 | 无效入口：控件可点但无响应或文案与功能不符 | 登录页辅助入口；表单字段标签 | 点击页面内全部可点文本与按钮；对照表单 label 与 placeholder | 每个可点控件有明确反馈或明确置灰/移除；label、placeholder、提示语指向同一字段名 | partial | enhance-existing |
| CAMEL-BP-017 | 拖拽排序失效或顺序未持久化 | 拖拽列表控件；保存后刷新 | 拖动第 2 项到第 1 位；拖拽后不保存直接刷新 | 拖拽后顺序立即变化；保存后刷新顺序保持 | partial | enhance-existing |
| CAMEL-BP-018 | 删除后数据不可恢复/不可重建或残留脏数据 | 删除确认弹窗；删除后列表与计数 | 删除后立即重新创建同名对象；删除后刷新列表 | 删除后列表不可见且详情 404/403；同名重建成功（或给出明确冲突提示） | none | add-minimal-case |
| CAMEL-BP-019 | 弹窗内次级动作打断主任务（跳转/关闭上下文丢失） | 搭配完成弹窗按钮；弹窗关闭后返回路径 | 搭配完成弹窗点保存日记；弹窗内点击任意次级按钮 | 次级动作以 toast 反馈并留在弹窗；弹窗内可继续购买 | partial | enhance-existing |
| CAMEL-BP-020 | 手势/滑动手势区域失效无法浏览 | 底部配件横向列表；换装组件面板 | 配件数量超过一屏后横向滑动；竖屏/横屏切换后滑动 | 可滑动到末项且选中生效；滑动不触发父级滚动冲突 | partial | enhance-existing |
| CAMEL-BP-021 | 后端参数校验缺失，非法入参统一 500/NPE | 接口入参校验层；详情/更新接口对象存在性 | 缺必填参数；传不存在 ID | 返回 400/404 与可读 business code+message；不返回 500/兜底编号/堆栈 | partial | enhance-existing |
| CAMEL-BP-022 | 对象级越权（IDOR）与横向数据访问 | 详情 GET 接口；更新/删除接口 | 用 B 的 token 访问 A 的资源 ID；替换路径参数为他人 ID | 返回 403 或 404 且不返回资源内容；DB 无变更 | strong | skip |
| CAMEL-BP-023 | 敏感信息明文暴露（Redis/验证码/密钥） | 网络端口暴露；验证码接口响应 | 公网直连 Redis 端口；抓取 /auth/code 响应体 | 中间件仅内网/白名单可达；响应体不含验证码答案 | partial | enhance-existing |
| CAMEL-BP-024 | 业务状态机非法迁移未被拦截 | 订单状态操作按钮；状态变更接口 | 对已取消订单调用发货/备货接口；同一订单并发两个状态动作 | 非法迁移返回业务错误并保持原状态；按钮按状态置灰/隐藏 | partial | enhance-existing |

| CAMEL-BP-026 | 大分页/慢接口缺少上限导致长耗时 | 列表接口分页参数校验；慢查询日志 | pageSize=1000/10000；pageNum 超末页 | pageSize 超上限被拒绝或截断到上限；P95 < 2000ms | strong | skip |
| CAMEL-BP-027 | 第三方回调验签/异常处理不一致 | 回调入口鉴权；回调幂等处理 | 无签名回调；错误签名回调 | 错误签名返回 401/403 且不落业务数据；重复回调幂等不重复入账 | strong | skip |
| CAMEL-BP-028 | 后台已发布但 C 端未生效（缓存/版本不一致） | 发布版本号/构建时间；C 端资源 hash 对比 | 后台修复后未重新构建 dist；小程序新包未过审/未发布 | 可核对当前部署版本号与构建时间；发布后 C 端在约定 SLA 内可见新行为 | strong | skip |
| CAMEL-BP-029 | 前端仅隐藏 UI 未做服务端授权（直连 API 可绕过） | 菜单可见性；直接路由访问 | 用低权限 token 直连高权限接口；直接输入受限路由 URL | 服务端返回 403 且无数据；角色×接口矩阵全部符合预期 | strong | skip |
