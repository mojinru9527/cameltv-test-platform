# Agent Team 批次模式：完整 / 轻量

> 事实源：`.claude/skills/cameltv-agent-team/SKILL.md`「批次模式」。本文件为详细判定与豁免记录规范。

## 1. 两档定义

| 档位 | 适用场景 | 强制工件 | 豁免记录 |
|------|---------|---------|---------|
| 完整批次 | 新功能 / 重构 / 配置 / Schema / 引入新行为、新接口、新配置、新依赖 | PRD + PM + Design + Dev（代码+看板）+ QA + Leader 六件 | 无 |
| 轻量批次 | 验收 / 修复 / 纯文档 / 纯证据 / 内部流程工具（不含新接口/新配置） | PRD-lite + QA + Leader 三件 + 看板 | PRD-lite 记录 `mode: light` + 理由 |

## 2. 判定流程（Product 第 1 步执行）

```text
需求输入
  ├─ 是否引入新行为/新接口/新配置/新依赖？
  │     ├─ 是 → 完整批次（六部门）
  │     └─ 否 → 是否仅为验收/修复/文档/证据/内部工具？
  │            ├─ 是 → 轻量批次（三件 + 看板）
  │            └─ 否 → 完整批次（拿不准按完整）
```

## 3. 轻量批次豁免记录格式

PRD-lite 头部必须含：

```markdown
mode: light
豁免理由: {一句话，指向 SKILL.md 判定标准}
非目标: {明确不做的新行为/新接口/新配置}
```

## 4. 两档共同的强制项（不可因轻量而免除）

- QA 硬门禁（typecheck/build/ruff/import/Alembic，按变更域）
- Leader 判决 + 流程回写 + 复盘卡
- C 条件纳入/豁免 + 看板更新
- PR 审计与用户一次总确认（推送+PR+合入）

## 5. 与 AGENTS.md 的关系

AGENTS.md 的 Git 门禁（分支/PR/审计/确认）对所有批次一视同仁。本文件只定义部门工件档位，不降低 Git 门禁。若 AGENTS.md 后续同步双档措辞，以仓库两个事实源对齐后的版本为准。
