# Agent Team 复盘卡模板

> 事实源：`.claude/skills/cameltv-agent-team/SKILL.md`「复盘卡」。QA 报告末尾与 Leader 判决末尾强制附复盘卡（Batch 75 起）。

## 1. 字段定义

| 字段 | 定义 | 示例 |
|------|------|------|
| 计划耗时 | 计划 vs 实际（小时） | 计划 6h / 实际 7.5h |
| 缺陷 | P0/P1/P2/P3 计数 | 0/1/3/5 |
| 返工次数 | 打回/重做次数（Leader 打回、QA FAIL 后重提） | 2 |
| 根因分类 | 需求不清 / 技术债 / 外部依赖 / 工具链 / 流程 | 外部依赖 |
| 下次避免 | 1 条可执行动作 | 验收批次先检查外部前置条件清单再排期 |

## 2. 模板

```markdown
## 复盘卡
| 计划耗时 | 缺陷(P0/P1/P2/P3) | 返工次数 | 根因分类 | 下次避免 |
|----------|-------------------|----------|----------|----------|
| {计划 vs 实际} | {n/n/n/n} | {n} | {分类} | {1 条动作} |
```

## 3. 根因分类定义

| 分类 | 含义 |
|------|------|
| 需求不清 | 验收标准缺失/歧义导致返工 |
| 技术债 | 存量代码缺陷/设计问题拖慢本批 |
| 外部依赖 | 第三方服务、外部前置条件、凭据/账号阻塞 |
| 工具链 | 构建/测试/CI/脚本/环境问题 |
| 流程 | 门禁、工件、确认环节造成的损耗 |

## 4. 聚合与使用

- 周汇总（`cameltv-daily-summary`）按批次聚合复盘卡，输出：平均耗时偏差、缺陷分布、Top 根因、Top 下次避免动作。
- 每 10 个批次技能健康审计引用聚合结果，判断流程是否需要调整。
- 复盘卡数据进入 `docs/agent-team/retro-data/`（可选）或直接由周汇总脚本读取工件。
