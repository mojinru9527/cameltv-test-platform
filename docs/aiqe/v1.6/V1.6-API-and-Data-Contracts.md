## 1. 目标策略（V16-001，已落地）

### 1.1 `ResolvedExecutionPolicy`（不可变快照）

| 字段 | 类型 | 说明 |
|---|---|---|
| `decision` | `ALLOW/DENY/UNAVAILABLE/MISSING_BINDING` | 唯一授权判定入口 |
| `project_id` / `environment_id` | `int` | 绑定作用域 |
| `policy_id` | `str \| null` | `aiqe_target_policies.id` |
| `policy_version` | `int` | 单调版本 |
| `policy_hash` | `str` | 判定字段规范化 JSON 的 sha256（`aiqe.target-policy.v1`） |
| `allowed_hosts` / `allowed_ports` / `allowed_schemes` | `tuple` | HTTP/浏览器目标 |
| `allow_private_cidrs` | `tuple[str]` | 仅管理员可写 |
| `blocked_cidrs` | `tuple[str]` | 云元数据/链路本地等，优先级最高 |
| `allowed_methods` / `max_redirects` / `verify_tls` | — | 请求约束 |
| `expires_at` | `datetime \| null` | 授权有效期（默认 300s） |
| `reason_code` | `str \| null` | `RUN_ENVIRONMENT_MISSING` / `NO_POLICY_CONFIGURED` / `POLICY_RESOLVE_ERROR` / `EXPLICIT_DENY` |
| `resolved_addresses` | `tuple[str]` | 预留：DNS 解析结果（实际 pinning 在执行器/代理层） |

### 1.2 策略解析入口

```python
resolve_execution_policy(db, run, node=None, *, project_id=None, environment_id=None, now=None) -> ResolvedExecutionPolicy
```

- `run.environment_id` 缺失且无项目级策略 → `MISSING_BINDING`；
- 策略表查询异常 → `UNAVAILABLE`（不得降级为 DENY 后走 legacy）；
- `policy_json.deny_all=true` 或 `decision=DENY` → `DENY/EXPLICIT_DENY`。

### 1.3 Workflow 策略迁移标记

`aiqe_workflow_definitions.policy_status ∈ {UNREVIEWED, MIGRATED, NEEDS_POLICY_REVIEW}`。
`NEEDS_POLICY_REVIEW` 时 `launch_run` 抛 `WORKFLOW_NEEDS_POLICY_REVIEW`。

## 2. 外部 Runner 载荷协议（V16-001，已落地）

`GET /api/v1/execution-jobs/{job_id}/payload`（`X-AI-Agent-Token`）

- AIQE Job：服务端**每次拉取重新解析策略**；
  - `ALLOW`：`payload.target_policy` + `payload.target_policy_hash` 返回；
  - 非 `ALLOW`：HTTP 409，`detail = {code, decision, policy_hash, policy}`，
    同时节点/Job 收口 `BLOCKED`，**不下发可执行载荷**。
- `POST /{job_id}/report`：AIQE Job 的上报同样受策略约束；非 ALLOW 时即使
  `status=success` 也收口 `BLOCKED`（服务端不变量，不信任 Runner）。

Runner 侧要求（`scripts/qa/aiqe_local_runner.py`）：
无 `target_policy` 或非 ALLOW → 直接上报 `BLOCKED`，不执行任何节点。

## 3. 浏览器拦截证据（V16-002，已落地）

`DriverResult.data` 增加：

```json
{
  "security_denials": [
    {"kind": "route|egress", "code": "PORT_NOT_ALLOWED", "host": "127.0.0.1",
     "path": "/leak", "resource_type": "fetch", "navigation": false,
     "policy_version": 1, "policy_hash": "..."}
  ],
  "denied_navigation": false,
  "target_policy": {"decision": "ALLOW", "...": "..."}
}
```

- 只记录 host/path，**不记录** header/query 值；
- Artifact：`security-denials.json`（存在拒绝时）；
- RunEvent：`security.ssrf_blocked`（count + 前 20 条 + node/driver）。

## 4. Secret Handle（V16-003，目标态）

```text
Driver 响应 → OutputSchema/SecretClassifier → SecretVault.put()
           → outputs 替换为 vault://<opaque-id> → 持久化/事件/Artifact
           → 授权 Consumer 通过 SecretResolver 获取短时明文
```

| 契约 | 要求 |
|---|---|
| Handle ID | `uuid4`，不含明文/hash/片段 |
| 元数据 | `project_id/run_id/producer_node_id/secret_type/consumer_scope/expires_at/revoked_at/access_audit_id` |
| 解析校验 | project + run + producer→consumer + 有效期 + consumer scope |
| API | Run Detail 默认返回 `***`/`secret://...`，无明文端点 |
| 失败语义 | Vault/KMS 不可用 → 节点 BLOCKED/ERROR，不写明文 |

## 7. Assertion 与 Run Outcome（V16-009，目标态）

```json
{"assertion_id": "...", "kind": "jsonpath|http_status|text_contains|db_value_eq",
 "subject": "...", "operator": "eq|contains|gte", "expected": "...",
 "actual_source": "response.body", "severity": "P0", "required": true,
 "timeout_ms": 5000, "evidence_required": true, "version": 1}
```

Run `PASSED` 条件：所有 mandatory business 节点 terminal；所有 required assertion
PASS；至少一个有效业务 Oracle；无 FAIL/BLOCKED/ERROR/UNKNOWN；required evidence 可验证。

## 10. 错误码约定（V1.6 新增/统一）

| 错误码 | 场景 |
|---|---|
| `TARGET_POLICY_DENIED` | 显式策略拒绝 |
| `TARGET_POLICY_UNAVAILABLE` | 策略存储/解析异常 |
| `TARGET_POLICY_MISSING_BINDING` | Run 未绑定 Project/Environment/Policy |
| `TARGET_POLICY_EXPIRED` | 授权过期 |
| `CAPABILITY_REQUIRED` | 节点能力未声明/未授权 |
| `CAPABILITY_UNAVAILABLE` | Driver/设备/依赖不可用 |
| `SSRF_BLOCKED` | 主导航被目标策略拦截 |
| `WORKFLOW_NEEDS_POLICY_REVIEW` | 旧 Workflow 未迁移 |
| `WORKFLOW_DB_OVERRIDE` | DB 节点携带 SQL/表白名单/连接 |
| `QUERY_NOT_REGISTERED` / `QUERY_DENIED` | Registry 未登记/租户越权 |
| `INVALID_EVIDENCE` | Agent 引用无效证据（目标态） |
| `BLOCKED` / `UNKNOWN` / `NOT_EVALUATED` | 不贡献 PASS 的终态 |
