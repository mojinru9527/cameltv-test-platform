## 3. 回滚策略

- 应用回滚 ≠ 数据回滚：先回滚代码，再按迁移的 `downgrade` 能力决定是否回滚 schema。
- 不可逆迁移（如契约阶段删除旧列/旧表）必须：
  1. 保留至少一个版本的双读窗口；
  2. 提供 `scripts/aiqe/recover_*.py` forward-fix 脚本；
  3. 备份 + 恢复演练记录归档到 `work-logs/evidence/aiqe-v16/`。
- `NEEDS_POLICY_REVIEW` 的 Workflow 在回滚后仍禁止调度（安全不变量优先于可用性）。
