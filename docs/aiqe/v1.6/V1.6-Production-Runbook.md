## 1. 部署拓扑（目标态）

| 组件 | 职责 | 最小权限 | 网络 |
|---|---|---|---|
| API | 控制面：Launch/Preflight/查询/审批 | DB 读写（仅自有库） | 入站 TLS；出站仅 Vault/KMS |
| Worker | 认领 ExecutionJob、执行 http/db 节点 | DB 读写；只读查询账号 | egress deny-by-default |
| Browser Runner | Playwright 节点 | 无 DB 凭据；仅对象存储上传 | egress 仅策略目标 + 对象存储 |
| Device Runner | Appium/真机/小程序 | 无 DB 凭据 | 设备网段 + 对象存储 |
| Vault/KMS | Secret Handle 明文 | 仅 API/Worker 可解密 | 内网 |
| 对象存储 | Artifact | 短期签名 URL | 内网/受控公网 |

**硬性要求**：非 root、只读根文件系统（临时目录除外）、CPU/内存/进程/文件描述符限制、
云元数据地址强制阻断、Runner egress deny-by-default（第四层防护）。

## 3. 环境变量（AIQE 相关）

| 变量 | 说明 | 生产要求 |
|---|---|---|
| `AIQE_INPROCESS_EXECUTOR_ENABLED` | 是否启用进程内 Worker | 生产建议 `true` 或由外部 Runner 承担；两者都必须经过策略校验 |
| `AIQE_DB_READONLY_URLS` | 查询注册表只读连接（JSON 映射） | 只读账号、限定 schema、独立连接池 |
| `AIQE_SECRET_*` / `AIQE_SECRETS_JSON` | Runner 运行时注入 secret | 由 Secret Manager 注入，禁止写入镜像/仓库 |
| `AIQE_TARGET_POLICY_TTL_SECONDS`（规划） | 授权有效期 | 默认 300s；不得调大超过发布窗口 |
| `PLAYWRIGHT_BROWSERS_PATH` | Chromium 路径 | 固定镜像 digest |

**禁止**：把 token/密码写入命令行参数、镜像层、Workflow input、DB 明文列。

## 4. 灰度阶段与停止条件（§8.4）

| 阶段 | 内容 | 进入条件 | 停止条件 |
|---|---|---|---|
| Stage 0 | 离线验证（单测/集成/安全/E2E） | 全部门禁绿 | 任一 P0 失败 |
| Stage 1 | Shadow：只读影子执行，不写业务数据 | Stage 0 + 策略/Secret 复核 | 出现明文/SSRF/跨租户 |
| Stage 2 | 内部 Dogfood：限定项目/环境/Driver | 管理员显式策略；手工审批外部副作用 | 假 PASS / 重复副作用 |
| Stage 3 | 小流量：低风险项目/Workflow，限并发/超时/域名 | Stage 2 观察 ≥1 天 | 告警/误报/漏报超阈值 |
| Stage 4 | 扩大范围：观察完整业务周期 | Stage 3 稳定 | 资源/失败恢复异常 |
| Stage 5 | GA：Gate A–G 全部通过并签署 | 独立验收完成 | — |

**任何阶段出现以下情况立即停止扩大并回滚**：
Secret Canary 明文 > 0；SSRF 目标实际收到被拒绝请求；跨 Project 访问成功；
Run PASS 无业务 Assertion/Required Evidence；Noise/Regression 有 QUEUED 无 Job；
Worker fencing 失效导致迟到结果覆盖；错误率/延迟超 SLO 无法恢复。

## 6. 部署步骤（暂存，V16-024 完成后生效）

1. 冻结 release commit；构建镜像并记录 digest；
2. 备份数据库；在 staging 用脱敏副本演练迁移；
3. 部署 API → Worker → Browser Runner → Device Runner（逐组件健康检查）；
4. 执行 `V16-001` 策略迁移命令（dry-run → 管理员补策略 → apply）；
5. 冒烟：创建受控 Run（Allow 目标 1 次 + 拒绝目标 0 次），核对 RunEvent/Artifact；
6. 开启 Shadow，观察 24h；按 §4 推进。
