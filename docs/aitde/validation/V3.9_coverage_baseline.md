## 3. Flaky / 集成测试观察（V39-008 交叉）

覆盖回归中 `tests/aitde/v34/test_approval_workflow.py::test_approval_gate_reject_aborts_before_dangerous_step`
**fail**，根因为 `temporalio.service.RPCError: workflow execution already completed` ——
该测试依赖**本地 Temporal Server**（`localhost:29795`），workflow 在 reject signal 前已完成，
属**集成/竞态**，非 V3.9 变更引入。已登记为 Flaky 候选（V39-008），其运行证据路径为
CI 全量 + Temporal 服务。

## 4. 豁免/基线阈值（V3.9 定稿）

- **达标线**：纯逻辑/策略/模型/模式层 ≥ 85%；核心 `service/repository` 层达标依赖 CI 全量。
- **豁免清单**：上表「⚠️ 大缺口」项（scenario/mission/sources 等 service/repository）豁免本轮
  离线清零，**豁免对象为「需 DB/服务集成」而非「逻辑缺失」**；随 CI 集成测试补足。
- **禁止以跳过/删除测试来抬覆盖率**。
