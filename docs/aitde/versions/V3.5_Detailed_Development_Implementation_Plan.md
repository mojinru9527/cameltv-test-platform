# 0. 版本目标

> **在没有 Git 仓库权限的情况下，通过测试环境指纹发现新 Build，选择需要回归的 Scenario，持续自动运行并形成 RED→GREEN 验收状态和 Quality Gate。**

全版本共享不变量：

```text
Frozen Contract 不可直接修改
ScenarioVersion 精确绑定 ContractVersion
AI 不拥有正式 PASS/FAIL 裁决权
Required Oracle + Deterministic Assertion + Evidence 才能形成可信 PASS
Runtime/Data/Environment 问题不能伪装成 BUSINESS_FAIL
Production 默认只读
```

# 3. Environment Fingerprint

Probe 来源：

```text
/version
/health
/info
response header
OpenAPI hash
DB migration table
static asset hash
tester build label
```

项目定义 `FingerprintProfile`：

```json
{
  "probes": [
    {"type":"http_json","url":"/version","jsonpath":"$.version"},
    {"type":"openapi_hash"},
    {"type":"static_asset_hash"}
  ]
}
```

Probe 失败：

- 记录 missing；
- 不直接当作新 Build；
- fingerprint confidence 不足时要求 Tester Confirm。

# 4. ImpactPlanner v1

V3.5 只做确定性基础版本：

```text
Scope/Module binding
API endpoint binding
Scenario priority
last business failure
project regression rule
```

无法判断时：

```text
fallback = configured Full/Smoke RunProfile
```

P0 默认 mandatory，不能因为“影响不确定”被全部排除。

完整 Lineage/Smart Regression 放 V3.7。

# 5. Quality Gate v2

默认：

```text
G1 Scope Approved
G2 Contract Frozen
G3 P0/P1 Scenario Coverage Complete
G4 Required Oracle Coverage Complete
G5 Required Scenario Executed for current Build
G6 P0 BUSINESS_FAIL = 0
G7 P0 INCONCLUSIVE = 0
G8 Required Evidence Complete
G9 Run EnvironmentSnapshot == target Build
G10 Run ContractVersion == current Frozen ContractVersion
```

明确删除旧思路：

```text
execution_total == 0 → PASS
```

# 6. Service / Class

- `EnvironmentFingerprintService`：执行 Probe 并生成稳定 hash。
- `BuildObserverService`：去重变化、生成 BuildObservation。
- `ImpactPlannerV1`：规则型基础选择。
- `ExecutionCampaignService`：固定某次 Build 的 selection snapshot。
- `ContinuousAcceptanceWorkflow`：Trigger→Build→Campaign→fanout→Gate。
- `QualityGateEvaluator`：确定性 G1-G10。
- `TriggerService`：manual/schedule/fingerprint/webhook。
- `AcceptanceSummaryService`：Build 间 RED/GREEN diff。
- `LegacyScheduleAdapter`：现有 Schedule → Trigger。
- `LegacyTestPlanAdapter`：现有 TestPlan → Campaign/RunProfile。

# 7. Backend API

- `POST   /api/v2/environments/{id}/fingerprints/capture` — 采集
- `GET    /api/v2/missions/{id}/builds` — Build Timeline
- `POST   /api/v2/build-observations/{id}/plan` — 生成 Campaign
- `GET    /api/v2/campaigns/{id}` — Campaign 详情
- `POST   /api/v2/campaigns/{id}/run` — 执行
- `GET    /api/v2/missions/{id}/acceptance` — 当前验收
- `GET    /api/v2/missions/{id}/acceptance/history` — 历史
- `POST   /api/v2/missions/{id}/quality-gates/evaluate` — 评估
- `POST   /api/v2/quality-gate-results/{id}/override` — 授权 override
- `GET    /api/v2/triggers` — Trigger
- `POST   /api/v2/triggers` — 创建 Trigger
