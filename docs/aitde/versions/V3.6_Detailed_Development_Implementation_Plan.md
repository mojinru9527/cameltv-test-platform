# 0. 版本目标

> **以只读、可审计、脱敏为前提，把生产真实行为和数据拓扑引入 Evidence Plane，用来发现需求遗漏、补充 Scenario、构建测试数据模板，而不是让 AI 自由修改生产。**

全版本共享不变量：

```text
Frozen Contract 不可直接修改
ScenarioVersion 精确绑定 ContractVersion
AI 不拥有正式 PASS/FAIL 裁决权
Required Oracle + Deterministic Assertion + Evidence 才能形成可信 PASS
Runtime/Data/Environment 问题不能伪装成 BUSINESS_FAIL
Production 默认只读
```

# 1. 绝对边界

Production 默认只允许：

```text
Browser Observe
ReadOnly Explore
HTTP GET/HEAD
明确 allowlist 的查询型 POST
DB SELECT only
```

默认禁止：

```text
CREATE/UPDATE/DELETE/DDL
支付/下单/退款
充值/提现
发布/评论/消息发送
修改用户/订单/会员状态
```

Production 是 Evidence Source，不是主 Test Runtime。

# 3. PROD_RO Worker

V3.4 的 `PROD_RO` Worker 本版正式启用。

必须同时满足：

```text
network_zone = PROD_RO
DB account = database-level READONLY
Policy profile = prod_ro
restricted capabilities
separate Secret scope
mTLS
full audit
```

应用层 `readonly=true` 不是安全边界；数据库账户本身必须无写权限。

# 4. Service / Class

- `ProductionObserverService`：创建/管理 Observe/ReadOnly Explore Session。
- `ReadOnlyBrowserPolicy`：语义动作风险判定，默认 deny 写类操作。
- `XhrEvidenceService`：升级现有 xhr_capture，改持久 Session/Workflow。
- `ProductionDbExplorer`：SELECT only、row limit、timeout、schema allowlist。
- `PiiClassifier`：字段名+内容分类。
- `MaskingService`：按 Profile 脱敏，生成 Mask Validation Report。
- `EntityGraphExtractor`：以业务根实体为入口抽取关联拓扑，限制深度/节点/行数。
- `ProdTemplateBuilder`：脱敏 Graph → 可测试模板。
- `TemplateMaterializer`：调用 V3.2 Fixture 写入 Test Environment。
- `ProductionEvidenceToDesignService`：真实状态/路径 → SourceArtifact / Ambiguity / Scope Change / Scenario Gap Proposal。

# 5. XHR Capture 改造

现有 `xhr_capture_service` 的读操作过滤经验可以复用，但要升级：

```text
进程内 _TASKS
→ persistent observation session

hardcoded base URL
→ Environment.base_url

raw payload
→ EvidenceSanitizer

standalone files
→ EvidenceArtifact / ObservedJourney / SourceArtifact
```

关键词过滤只能是额外防线，最终边界由 Policy Gateway + network + real read-only credentials 保证。

# 6. DB ReadOnly 防线

三层：

```text
Layer 1 DB account permissions
Layer 2 Driver only exposes read APIs
Layer 3 Policy / SQL parser / allowlist / limit
```

即使 Layer 2/3 有 bug，Layer 1 仍应阻止写入。

# 10. AI / Skill

Prompt：

```text
production_evidence_gap_analysis_v1.md
journey_summary_v1.md
entity_graph_explanation_v1.md
```

AI 只做：

- 总结真实路径；
- 找 Contract/现状冲突；
- 生成 Ambiguity/Gap Proposal；
- 解释 Entity Graph。

禁止：

```text
自动冻结新 Contract
把生产当前行为直接当标准
自动提升权限
自动执行生产写操作
```

新增：

```text
.claude/skills/test-production-evidence-review/SKILL.md
.claude/skills/test-data-masking-review/SKILL.md
```
