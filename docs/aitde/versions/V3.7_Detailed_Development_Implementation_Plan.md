# 0. 版本目标

> **建立完整 Evidence Lineage 和 ChangeSet，把 PRD/OpenAPI/DB/UI/环境变化映射到受影响 Scenario，在可解释、可审计、可回退的前提下进行精准回归。**

全版本共享不变量：

```text
Frozen Contract 不可直接修改
ScenarioVersion 精确绑定 ContractVersion
AI 不拥有正式 PASS/FAIL 裁决权
Required Oracle + Deterministic Assertion + Evidence 才能形成可信 PASS
Runtime/Data/Environment 问题不能伪装成 BUSINESS_FAIL
Production 默认只读
```

Smart Regression 的首要目标是：

# 5. Impact Algorithm v1

示例：

```text
Requirement Fragment changed
→ Scope
→ Intent
→ Scenario

OpenAPI response schema changed
→ Endpoint binding
→ API Oracle / Scenario

DB enum changed
→ DataEntity / DB Oracle
→ Scenario

Observed Journey new state
→ Business Flow
→ Scenario candidate
```

风险权重：

```text
P0/P1
Contract rule changed
Last BUSINESS_FAIL
Historical defect
Recently changed
Production real-world signal
```

任何无法建立 Lineage 的变化：

```text
UNKNOWN_CHANGE
→ CoverageGuard
→ fallback RunProfile
```

# 6. Service / Class

- `LineageService`：建边、去重、查路径、dangling edge 检查。
- `LineageBackfillService`：把 V3.0-V3.6 已有关系补成 Edge。
- `ChangeSetService`：把不同 Diff 规范化。
- `RequirementDiffProvider`：Fragment/结构/语义辅助 Diff。
- `OpenApiDiffProvider`：operation/schema/required/status/content-type breaking diff。
- `DbSchemaDiffProvider`：table/column/index/enum/schema version。
- `UiDiscoveryDiffProvider`：语义控件/页面/Action Graph 变化。
- `HistoricalRiskProvider`：BusinessFail/Defect/Flaky 等风险信号。
- `ImpactAnalyzer`：确定性图遍历与 score。
- `RegressionSelector`：mandatory P0 + impacted + safety fallback。
- `CoverageGuard`：选择集过小、未知变化、低置信时强制 Full/Smoke fallback。
- `ImpactExplanationService`：输出 path/reason，不依赖 AI 才能解释。
- `SmartRegressionCampaignFactory`：把 Selection 固化为 V3.5 Campaign。

# 9. AI

AI 可以用于：

```text
Requirement semantic diff summary
Unknown change clustering
Impact explanation wording
```

但最终 Selection 由：

```text
RegressionSelector + CoverageGuard
```

决定。

新增 Prompt：

```text
impact_semantic_assist_v1.md
```

硬规则：

```text
AI 不得删除 P0 mandatory Scenario
AI 不得关闭 fallback
AI 输出只是 assist evidence
```

# 10. Smart Regression Guard

默认项目策略：

```text
P0 always include
P1 impacted + recent fail
Unknown change → fallback
Algorithm version change → shadow compare
```

在达到验证门槛前：

```text
Smart Selection = Shadow
Full Regression = Formal
```

达到 Recall/False Negative 门槛后才逐步切正式。
