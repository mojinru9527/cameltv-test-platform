# 0. 版本目标

> **让 Mission/Contract/Scenario/Run 成为唯一正式事实源，完成旧入口收敛，并补齐 SSO、RBAC、Audit、Retention、Encryption、HA、Backup、Model & Cost Governance 和正式 Release Gate。**

全版本共享不变量：

```text
Frozen Contract 不可直接修改
ScenarioVersion 精确绑定 ContractVersion
AI 不拥有正式 PASS/FAIL 裁决权
Required Oracle + Deterministic Assertion + Evidence 才能形成可信 PASS
Runtime/Data/Environment 问题不能伪装成 BUSINESS_FAIL
Production 默认只读
```

# 4. API v1 Cutover

分阶段：

```text
Stage 1  Add Deprecation headers + usage telemetry
Stage 2  Disable writes for migrated canonical objects
Stage 3  Legacy pages read-only
Stage 4  Redirect primary navigation
Stage 5  Remove dead write code
```

每个 v1 endpoint 建 Inventory：

```text
path/method
current caller
owner
traffic
replacement v2
deprecation stage
sunset date
rollback switch
```

不能凭“看起来没人用”直接删除。

# 5. TestCase Cutover

规则：

```text
scenario_id IS NOT NULL
→ Functional Projection
→ business expected readonly

legacy standalone
→ migrate / archive / remain legacy read-only
```

Scenario-bound Case 如果用户修改业务 Expected：

```text
UI 引导 → ChangeProposal
```

不能写回 TestCase expected_result 成第二事实源。

# 7. Audit

重要 Audit 不仅记录 CRUD，还记录：

```text

Policy Deny/Approve

```

Audit 要支持只读检索/导出，并有自身 retention。


```text

```

# 10. Model Governance

根据 Source Sensitivity 路由：

```text
PUBLIC
INTERNAL
CONFIDENTIAL
RESTRICTED
```

模型更新：

```text
Golden Evaluation
→ Compare metrics
→ Security/Cost check
→ Approval
→ Canary projects
→ Rollout
```

不允许直接全平台换 model/prompt。

# 11. Cost Governance

统计：

```text
AI input/output usage
Object Storage bytes
Browser minutes
Worker runtime
Temporal workflow/activity
```

项目 Budget：

```text
warn
throttle optional AI
lower retention of optional artifacts
disable optional video（如项目允许）
```

永远不能因为成本静默跳过：

```text
Required Oracle
Required Evidence
Production safety
Contract review
```

# 13. Service / Class

- `LegacyUsageInventoryService`：记录 v1 endpoint/page/job 实际使用。
- `LegacyCutoverService`：按 Batch 迁移/校验/暂停。
- `CompatibilityPolicy`：endpoint 的 ACTIVE/DEPRECATED/READONLY/DISABLED。
- `RetentionService`：Artifact lifecycle。
- `GovernanceService`：例外审批与到期。
- `ModelPolicyService`：敏感等级/Provider/Model 路由。
- `CostLedgerService`：AI/Runtime/Storage usage。
- `BackupVerificationService`：备份恢复演练记录。
- `PlatformReadinessEvaluator`：平台级 Gate。
- `AcceptanceReportService`：Mission/Build/Contract/Scenario/Run/Proof 正式报告。
