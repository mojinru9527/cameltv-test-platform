# 生产级验收外部前置条件清单

> **用途**：集中登记生产级验收（Test5、AI、真机、迁移、DevOps、生产发布）的全部外部前置条件，
> 每解锁一项即登记「提供人 / 日期 / 授权范围」（对齐 C63-2），不登记不执行。
> **安全声明**：清单只记录提供物名称与存放位置，**不含明文密码、Token、API Key、CA 证书**。
> 所有凭据由提供者自行写入本地未跟踪的 `.env` / `production.env`。

## 使用规则

1. 每项完成时更新「状态」与「登记」列；登记信息同步写入 C-CONDITIONS.md。
2. 未解锁项对应的验收步骤保持 `DEFERRED`，禁止用本地证据冒充。
3. 提供凭据时遵守：最小权限、只读优先、不入库、不贴聊天明文。
