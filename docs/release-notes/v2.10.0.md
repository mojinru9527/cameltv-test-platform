## 2. 关键变更

- **AI 配置中心（新）**：`/ai-config` 项目级多提供方池；全平台 AI 功能统一按项目解析；env 凭据（AI_API_KEY/DSH_API_KEY 等）退役，迁移至平台内配置；无配置项目 AI 功能禁用并引导。
- **DSH 测试入口（升级）**：场景卡片 + 三步向导（输入→提供方/模型/模式配置→可编辑任务描述）；各业务页深链一键进入并预填。
- **产物闭环（新）**：DSH 场景任务成功 → 产物清单自动落知识中心「AI 审核台」（pending）→ 人工采纳后导入正式用例库（functional→case_type=manual、api→case_type=api）；requirement/ui_case 类型本期可审核、导入后续支持。
- **知识中心修复**：tab 切换不再拼接（已访问 tab 状态保留但显式隐藏）。

## 3. 已知风险

| 风险 | 等级 | 缓解 |
|------|------|------|
| 产物解析依赖 persona 输出契约（`## 产物清单` JSON） | 低 | 解析失败容错为「任务成功但 0 产物」，原始输出任务详情可查；幂等防重 |
| requirement/ui_case 产物暂不支持导入 | 低 | 审核台按钮禁用 + 明确提示；后续批次支持 |
| AI env 凭据退役后，存量项目需在「AI 配置」补配提供方 | 中 | 平台内配置页 + 各 AI 入口未配置引导；迁移为一次性成本 |
| DSH 场景任务默认团队·测试视角（tester persona） | 低 | 向导可切标准模式/开发视角 |

## 4. 回滚目标

- 制品基线：`v2.9.1`（上一可验证版本）
- 回滚方式：Docker 镜像回滚上一 tag / `git revert` 指定 PR（见 deploy/CLAUDE.md 与 cameltv-deploy 技能）

## 5. 部署

- test：每日固定窗口自动部署最近 main（Jenkins），本版本合入后随窗口生效。
- prod：每周发布窗口 + 审批（ADR-0015），需 VPN（vpn07）后经 Jenkins `DEPLOY_ENV=prod` 发布并做生产冒烟。
