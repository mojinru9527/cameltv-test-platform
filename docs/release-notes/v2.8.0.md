## 2. 关键变更

- **数据可信**：统计口径 5→1（statistics_service）、计划进度、trace is_deleted、需求覆盖率、AI 产物置信度。
- **质量闭环**：计划失败自动转缺陷/报告/通知（开关默认关）；执行失败根因三列 + 环境预检；执行→任务快照双向关联。
- **性能**：请求缓存/防抖/指数退避；mindmap 服务端 taxonomy 聚合（10.1MB→KB 级）。
- **编排**：功能用例入计划、UI 自动化↔用例映射回写、数据集参数化绑定、报告定时生成、调度停用原因。
- **体验/无障碍**：计划单一执行入口、任务删除/重跑、服务级批量生成用例、404 页、脑图键盘可达、知识中心 tab 状态保留等。

## 3. 已知风险

| 风险 | 等级 | 缓解 |
|------|------|------|
| 自动链路为新增行为，开关默认关闭 | 低 | 生产默认不写入；按计划显式开启 |
| 执行模型双向关联为增量登记（计划 API 执行新增 plan 任务） | 低 | 任务列表会多出 trigger_type=plan 条目；不影响统计口径 |
| 调度停用原因必填（新约束） | 低 | 前端弹窗 + 后端双重校验，历史停用项 reason 为空可后续补充 |
| C155-1 关闭、C156 无新条件 | - | 追踪器 0 硬错 |

## 4. 回滚目标

- 制品基线：`baseline-2026-07-22-audited`（上一可验证版本）
- 回滚方式：Docker 镜像回滚上一 tag / `git revert` 指定批次（见 deploy/CLAUDE.md 与 cameltv-deploy 技能）

## 5. 部署

- test：每日固定窗口自动部署最近 main（Jenkins），本版本合入后随窗口生效。
- prod：每周发布窗口 + 审批（ADR-0015），需 VPN（vpn07）后经 Jenkins `DEPLOY_ENV=prod` 发布并做生产冒烟。
