# 主链路用户手册（黑盒 / 业务测试工程师）

> **Batch 220 / B10** | 面向「测试工程师」的业务语言说明，不含引擎术语。  
> 目标：无指导也能跑通「建任务 → 审方案 → 执行 → 放行 → 知识复用」并交付可放行版本。

## 0. 一句话
平台 = **AI 版本验收工作台**：你只需用业务语言说「这个版本怎么测」，AI 帮你出方案、跑起来、整理证据；你只做两件事——**审方案** 和 **下结论**。

## 1. 登录与首页
1. 打开平台地址，登录你的账号。
2. 首页 = **我的待办**：今天要审什么、什么在跑、什么失败，一目了然。

## 2. 建版本验收任务（3 步）
进入「版本验收」，点「建任务」：
1. **填需求**：写任务标题、版本号、变更模块（如「登录, 支付, 订单」）。
2. **审方案**：点「生成验收方案」，AI 会给出功能 / 接口 / 自动化条目。
   - 每个条目有 **置信度** 与 **待确认问题**。
   - 你对每条做 **采纳 / 修改 / 追问 / 删除**（人工逐条审，审完才冻结）。
3. **确认**：点「确认并进入待审」，方案进入评审。

## 3. 执行与证据
回到任务详情，点「一键运行」：
- 平台按你采纳的方案条目跑一遍。
- 进度条 + 覆盖率（通过/失败/跳过/阻塞）。
- **证据回放**：每条执行的请求/截图/回放可查看。
- **失败自动分类**：业务 / 脚本 / 数据 / 环境；失败条目可「转缺陷草稿」。

## 4. 放行
放行页：
- 看 **通过率 / 覆盖 / 风险** 与缺陷清单。
- 三个按钮：**放行** / **有条件放行** / **打回**。
- 可绑定该版本对应的 **发布包 ID**，并「发送通知」。

## 5. 知识复用（下一版）
版本任务完结自动沉淀「这版怎么测的 + 下版复用建议」；下一版本建任务时 AI 自动带出。

## 6. 常见疑问
- **「版本验收」和「用例服务/接口测试/UI 自动化」什么关系？** 后者是资产库（专家工具），版本验收让你只管主线；需要时 AI 自动调用它们。
- **「执行引擎/DSH/Scenario」在哪？** 在专家界面，普通测试员不需要懂。
- **待确认问题怎么办？** 直接「追问」，AI 答复后会更新条目。
