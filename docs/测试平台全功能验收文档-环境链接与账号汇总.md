### 2.2 Docker 部署

#### v2 Docker Compose (`test-platform-v2/deploy/docker-compose.yml`)

| 服务 | 容器名 | 镜像 | 端口映射 | 说明 |
|------|--------|------|----------|------|
| `postgres` | `cameltv-tp-postgres` | `postgres:16-alpine` | `5432`（内部暴露） | 用户 `cameltv`，密码由 `.env` 注入 |
| `backend` | `cameltv-tp-backend` | `../backend/Dockerfile` | `8000`（内部暴露） | Python 3.12 + FastAPI，数据卷 `tp-data` |

**架构**: `Browser :80 → Nginx(前端) → /api/* → FastAPI(后端) → SQLite(/data/platform.db) 或 PostgreSQL`

**PostgreSQL 容器配置**:
- 用户: `${POSTGRES_USER:-cameltv}`
- 密码: `${POSTGRES_PASSWORD}`（必填，由 `.env` 注入）
- 数据库: `${POSTGRES_DB:-cameltv}`
- 默认数据库 URL: `sqlite:////data/platform.db`；可选: `postgresql://cameltv:<password>@postgres:5432/cameltv`
