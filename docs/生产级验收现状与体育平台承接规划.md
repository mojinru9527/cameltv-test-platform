### 4.4 平台自身角色权限模型（简述）

- 三种数据范围：`global` / `project` / `self`；RBAC 权限点按模块授权（如 `testcase:manage`、`wiki:diff`、`token:manage`、`notify:manage`）。
- `viewer` 只读集：workbench/trace/requirement/report/defect/dataset/knowledge 的 list+detail 与 view 权限；全部 create/update/delete/execute/import/manage/approve/run 明确不授予；写操作 403（测试 3/3）。
- 认证：JWT（HS256）+ BCrypt；浏览器主会话为 httpOnly Cookie（`cameltv_token`），Bearer 兼容回退；CSRF 默认开启；所有 API 需 `X-Project-Id`。

### 5.4 安全边界与合规

- **只读优先**：生产仅 GET/HEAD/登录只读会话，禁止写入/支付/发布/压测；`guardProductionRequests` 拦截非白名单请求。
- **脱敏**：截图/日志中账号、手机号打码（B4 口径）。
- **VPN 互斥**：测试环境用 OpenVPN、生产环境用 vpn07 tun 模式，两个通道不得同时挂；双 VPN 手册暂停使用，需重新审核网络边界后才可恢复。
- **凭据**：只写 gitignored `.env` / WSL 本地（chmod 600），不贴聊天、不入库（C63-2）。
- **测试断言**：遵循双 404 约定（C86-1）；不引入裸 `status_code == 404`。
