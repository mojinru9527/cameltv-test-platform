## 对账规则

1. 本清单与 `C-CONDITIONS.md`、菜单种子（`seed.py _MENUS`）、命令面板
   （`CommandPalette ALL_COMMAND_ROUTES`）互相对应；新增/移除能力时三处同步。
2. API-only 能力必须在 OpenAPI schema 与 README 中标注「API-only，UI 待接入」，
   不得在 PRD 中表述为普通用户可操作功能。
3. 移除死能力必须走一次独立审计批次，禁止本批顺带删除。
4. 每个「补 UI」决策在新批次 PRD 中必须引用本清单 ID。
