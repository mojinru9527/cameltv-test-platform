## 3. 配置「内网执行器」环境（Test5-接口）

在平台「环境配置」页编辑 `体育平台-Test5-接口`（环境 id=7，base_url=`http://camel-api-gateway05.svc.elelive.cn`）：

| 字段 | 值 | 说明 |
|---|---|---|
| 访问类型 access_type | `internal` | 平台（公网）不可直达该内网 |
| 执行模式 execution_mode | `runner` | 派发给内网执行器 |
| runner_key | `test5-internal-01` | 与该执行器脚本 RUNNER_KEY 一致 |

- [ ] 数据库：`UPDATE environment SET access_type='internal', execution_mode='runner', runner_key='test5-internal-01' WHERE id=7;`
- [ ] 平台 UI「环境配置」页可见这三字段并已设置。

> 其他纯内网项目同理：为每个内网环境设置 `access_type=internal, execution_mode=runner, runner_key=<唯一>`。

## 4. 启动内网执行器（在其能连内网的机器上）

```bash
# 在能连 Test5 内网/VPN 的机器（如开发机）
export PLATFORM_URL=https://swiftbugs.cn
export API_USERNAME=<平台账号>          # 有 apitest:execute 权限，如 sportsadmin
export API_PASSWORD=<平台密码>
export RUNNER_KEY=test5-internal-01
export PROJECT_ID=1
export RUNNER_BASE_URL=http://camel-api-gateway05.svc.elelive.cn   # 该内网网关
cd test-platform-v2 && python backend/scripts/executor/api_runner.py
# 认领并执行一条后退出（验证用）：
# python backend/scripts/executor/api_runner.py --once
```
