1. **需求 AI 提取/生成超时**（C102-1）：大文档 300s 网关 502；沿用本地生成通道。
2. **知识中心入库接口**（C102-2）：capture 409 已修复（Batch 108），vector_search 仍待验证。
3. **需求模块树直建**（C102-3）：Batch 110 落地直建脚本；平台 API 仍建议支持 md 直建。
4. **生产 vs 原型差异标注**（C102-4）：本期以文档矩阵+vision 走查落地；平台内标注 UI 待迭代。
5. **AI 生成截断**（C102-5/C103-6）：块级补全待迭代。
6. **wiki 生产启用**（B6）：WIKI_ENABLED 默认 OFF，需 Railway 变量启用。
7. **接口批量执行回填无 UI**（B8）：脚本回填；平台批量执行 UI 待迭代。
