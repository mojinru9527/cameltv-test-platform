## 1. 问题陈述

Batch 101 已把体育平台**契约/API 资产**接入测试平台生产（7 服务 899 端点、325 接口用例、生产环境、UI 只读冒烟、CI Token），但**功能层面仍是空白**：

- 用户端/运营后台需求文档（98 页 + 72 页原型）尚未导入平台；
- 平台需求模块/知识中心/用例脑图为 0，功能逻辑没有沉淀；
- 需求文档与生产页面实际功能没有联动，直接生成用例会脱离实际；
- 用户端、运营后台、konfi 之间的功能关联（模块作用 / 后台使用 / 配置项）没有梳理。

用户纠正方向（2026-08-06）：**先功能、后接口/UI**。第一期以「功能模块梳理」为核心：
需求文档导入测试平台 → 结合生产页面各功能模块做逻辑补充 → 需求与实际功能整体联动 →
再生成功能用例 → 用用例脑图和知识中心把用户端/运营后台/konfi 的功能逻辑梳理清晰。
过程中把平台使用较少或使用有障碍的地方登记，后续逐批迭代。

- As a **承接负责人**, I want 用户端/运营后台需求文档导入测试平台，so that 功能需求有据可查、AI 用例生成有输入。
