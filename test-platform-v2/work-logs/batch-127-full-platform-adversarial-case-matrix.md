- 每个功能至少包含正向与反向；有边界输入的功能必须包含边界。

## 4. 执行口径与结论

- `PASS`：生产只读/本地真实浏览器/后端全量测试中的适用层级均通过。
- `FIXED-LOCAL`：生产走查先发现缺陷，本分支已以失败测试锁定并在本地修复；须合入并进入发布火车后才可称为生产关闭。
- `PASS-CONTROLLED`：模块本身可达、权限与失败恢复通过；外部设备、凭据或存储未提供时明确显示未启用，未伪造成功。
- `PASS + C...`：本批验证主流程可用，但已知资产/外部性能债务继续由既有条件追踪。

最终证据：后端 `1233 passed, 3 skipped`；前端 `101 files / 391 tests`；生产构建成功；真实后端 Playwright `35 routes / 0 issues / 0 duplicate GET`；Alembic fresh DB 到唯一 head；C 审计 hard/warn `0/0`；common-bug HARD `0`。required checks 尚待 Draft PR 创建后执行，因此 B127-X12 当前处于“本地门禁通过、远端待执行”。
