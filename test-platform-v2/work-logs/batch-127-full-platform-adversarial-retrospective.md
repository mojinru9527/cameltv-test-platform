# Batch 127 — 复盘卡

| 项目 | 结果 |
|------|------|
| 计划 | 生产只读全功能走查 → 本地真实后端矩阵 → 对抗性 TDD → 双端全量 → Leader |
| 缺陷分布 | P0×0 / P1×10 / P2×4 / P3×0 |
| 返工 | 5 类：重复请求、受控 503 a11y、中文断言漂移、SQLite DDL、ADB 孤儿进程 |
| 主要根因 | 统计多事实源、把局部集合当全量、外部能力未产品化、第三方调用无终止边界、回归资产落后于路由 |
| 有效做法 | 生产只读和本地写路径分离；用不变量而非页面截图判断；全量回归后仍观察进程/日志残留 |
| 下次改进 | 路由矩阵从源码自动生成；OpenAPI 类型漂移加入 CI；设备/外部调用统一 timeout + process cleanup 契约 |

本批最重要的教训：HTTP 已返回不代表底层工作已结束；页面显示了数字也不代表数字拥有正确分母。验收必须同时检查用户可见结果、数据来源和运行时残留。
