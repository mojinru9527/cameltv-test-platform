# Batch 128 — Design Spec（游客壳、登录门禁与用例三级分类）

> **Design (🎨)** | Date: 2026-08-09 | Status: Ready

## 0. 技术体系与场景

真实栈：shadcn/ui + Radix + Tailwind + CVA；沿用现有主题 token，不新增视觉语言。使用场景是测试人员在桌面/平板上快速判断平台能力，访客先浏览能力、使用时完成登录或注册。

## 1. 游客平台壳

| 区域 | 规格 | 游客态 | 登录态 |
|------|------|--------|--------|
| 侧栏 | 复用 `Sidebar`、44px 触控目标 | 展示公开模块目录；点击调用统一门禁 | 权限菜单正常导航 |
| 侧栏底部 | 现有用户区高度 | “访客浏览”+“登录后使用完整功能” | 头像/昵称/邮箱 |
| 顶栏项目 | 现有 150/200px Select | 替换为“登录”“免费注册”按钮，不渲染空 Select | 项目切换器 |
| 主内容 | `p-4 sm:p-6` | 单一欢迎区 + 分组模块列表 + 注册 CTA | `<Outlet>` + 项目边界 |

游客模块目录采用紧凑分组列表，不使用重复的大卡片网格；每项显示图标、模块名和“登录后使用”。加载失败使用现有 Error 语义与重试，不能退化成空侧栏。

## 2. 登录 Dialog

- 组件：Radix `Dialog`，`sm:max-w-[420px]`；标题“登录后继续使用”，描述包含目标模块名。
- 表单复用登录页字段与 API，不产生第二套登录逻辑。
- 成功：关闭 Dialog，导航到记录的目标路径；失败：保留输入与后端 `detail/msg/message`。
- 次操作：“免费注册”进入 `/register`；“暂时浏览”关闭 Dialog。
- 焦点：打开后进入用户名；关闭恢复触发按钮；Escape 可关闭；`aria-describedby` 完整。

## 3. 普通注册

- 标题“创建免费账号”，副文案“注册后可创建项目并使用完整测试能力”。
- 邀请码根据公开策略显示为“邀请码（可选）”或“邀请码”；即使可选也保留输入，兼容管理员发码。
- 项目邀请 token 提示继续保留，并明确“注册后自动加入项目”。
- 底部同时提供“返回浏览平台”和“去登录”。
- 不新增装饰动效；提交态只在按钮内显示 Loader2，错误在表单顶部和字段级呈现。

## 4. 用例服务信息架构

类型页签顺序：`功能用例`（默认）→ `接口用例` → `UI 自动化` → `全部`。每项显示服务端 canonical 计数；小屏允许横向滚动，不压缩文字。

分类树：

```text
用户端 (n)
└─ 体育-用户端-功能 (n)
   └─ 安卓iOS
      └─ 赛事详情
         └─ 预测Pick (n)
运营后台 (n)
└─ 体育-运营后台-功能
   └─ 运营后台 / 赛事预测 / 奖励发放记录
接口测试 (n)
└─ 体育-接口测试 / ...
其他 (n)
```

- 一级端别使用稳定中文映射；未知数据归“其他”，禁止猜成用户端。
- 左树与顶部筛选均支持端别；选端别清空 domain/module，选 domain 清空 module。
- 模块路径 `/` 拆成视觉子层级，但最终叶节点以完整 module 值查询，避免破坏数据契约。
- 桌面保留 220px 树；平板/手机使用端别、域、模块三个 Select，不依赖隐藏树。

## 5. 脑图

- 页头增加“用例类型”和“端别”两个 Select，默认“功能用例/全部端别”。
- 标题改为“用例脑图（端别 → 模块 → 子模块 → 用例）”。
- 根层用端别，module 中的 `/` 每段生成一级；节点过长保留 markmap maxWidth 320。
- Loading/Error/Empty 与当前 `AsyncState` 保持；全屏/Escape 生命周期测试继续有效。

## 6. 无障碍与响应式

- 所有图标按钮保留 `aria-label`；页签使用 `aria-pressed`；模块项用真实 button。
- 对话框、菜单、Select 由 Radix portal，避免 Sidebar overflow 裁剪。
- 1440×900：侧栏+内容并列；768×1024：侧栏抽屉；390×844：CTA 全宽、类型页签横向滚动。
- 颜色只用 `bg-background/bg-card/bg-muted/text-foreground/text-muted-foreground/border/text-primary` 等语义类。

## 7. 设计 QA 预防项

| 级别 | 风险 | 门禁 |
|------|------|------|
| P1 | 游客直接路由挂载业务页并发 401 | MainLayout guest 分支不渲染 Outlet；Network 断言 |
| P1 | 登录 Dialog 与登录页行为漂移 | 复用同一个 LoginForm |
| P2 | 切用例类型后树计数仍是全量 | taxonomy 请求携带 case_type，query key 含类型 |
| P2 | 同名 module 跨 domain 误筛选 | 树键包含 surface/domain/full module |
| P2 | 生产显式旧变量仍关闭注册 | public-access 契约真实回显，发布清单提示 |

## 8. 设计签核

结论：**Ready**。实现必须以现有组件为主，不修改 `components/ui/*` 生成物。
