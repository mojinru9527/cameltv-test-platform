# Batch 128 — PRD Summary（公开访问、普通注册与用例分类体系）

> **Product (🟦)** | Date: 2026-08-09 | Status: Approved for implementation
> **mode**: full（引入公开访问状态机、注册策略与新分类接口）

## 1. 问题陈述

用户在生产平台走查中确认三项直接影响外放与用例可用性的缺口：

1. `/mindmap` 仍按 `domain → module → case` 展示，用户端与运营后台没有稳定的一级分组；
2. 根路由被 `RequireAuth` 整体拦截，未登录访客看不到平台模块；注册虽已实现，但生产默认关闭且邀请码必填，普通外部用户无法自助注册、创建项目；
3. 用例服务只呈现“全部/功能用例”两个页签，`api/ui` 已有数据却不可直接选择；模块分类也只有两级，无法表达“用户端/运营后台 → 对应模块 → 子模块”。

截图证据：`codex-clipboard-bfb55b3b-e9bc-41c7-9e07-c6a8b40c2a72.png` 中用例服务顶部只有“全部/功能用例”，左侧分类根节点为业务模块，没有用户端/运营后台分组；左下角为已登录管理员态，无访客入口证据。

历史根因：Batch 104 已实现邀请制注册，但把“游客浏览/使用时登录”明确列为后续；Batch 122 已规定体育用例域和 `入口/一级/二级` 路径，但前端分类与脑图未消费该结构。Batch 128 将两条已存在但断开的能力链闭环。

## 3. 非目标与 C 条件

- 不开放任何匿名业务数据接口；访客只获取模块名称、路径、图标和注册策略，实际页面/API 仍需登录。
- 不取消登录/注册限流、httpOnly cookie、CSRF、项目配额与租户隔离。
- 不删除邀请码和项目邀请链接；普通注册默认不要求平台邀请码，带项目邀请 token 时仍自动加入项目/组织。
- 不迁移或重写 7,559 条存量用例；分类通过兼容规则消费现有 `domain/module/case_type/case_id`。
- 不在本批执行生产部署或变更 Railway 外部变量；合入主干与发布火车分离。
- **纳入**：C122-4（用例结构与分类/脑图/详情联动走查）、C104-5（首补丁目录核验）、C75-1/2/3、C76-2、C78-1、C86-1、C63-3。
- **豁免**：C122-2、C123-2~4、C124-1~3、C125-1~4、C126-1~4、Test5/iOS/性能等外部项；均与本批公开访问和分类呈现无直接依赖，状态不变。

## 4. 用户故事与验收标准

### US-01 访客浏览平台能力

- Given 用户未登录，When 打开 `/`，Then 显示完整平台壳、公开模块导航、登录与免费注册入口。
- Given 用户未登录，When 点击侧栏模块或直接打开 `/testcase`，Then 不挂载用例页面、不发受保护业务 GET，并显示登录 Dialog。
- Given 登录成功，When Dialog 关闭，Then 进入原目标路径并恢复用户项目/权限菜单。

### US-02 普通用户注册并创建项目

- Given 普通外部用户未登录，When 打开 `/register`，Then 邀请码不是必填项，页面明确说明可直接注册。
- Given 用户提交唯一用户名、有效邮箱格式与至少 6 位密码，When 注册成功，Then 自动登录并进入“我的项目”，可创建项目且受既有配额约束。
- Given 注册来自项目邀请链接，When 完成注册，Then 继续自动加入对应项目与组织。
- Given 后端环境显式要求邀请码，When 用户未填写，Then 页面和接口均返回明确邀请码提示。

### US-03 用例服务类型与三级分类

- Given 项目含 `manual/functional/api/ui` 用例，When 打开用例服务，Then 默认只查询 canonical 功能用例，并显示四个类型页签及守恒计数。
- Given 选择接口或 UI 自动化页签，When 分类树刷新，Then 只统计该类型可见的端别/域/模块。
- Given 体育存量域 `体育-用户端-功能`、`体育-运营后台-功能`、`体育-接口测试`，When 请求 taxonomy，Then 分别落入用户端、运营后台、接口测试一级分组。

### US-04 脑图按端别和子模块展开

- Given 模块路径 `安卓iOS/赛事详情/预测Pick`，When 生成脑图，Then 层级为“用户端 → 体育-用户端-功能 → 安卓iOS → 赛事详情 → 预测Pick → 用例”。
- Given 用户切换端别或用例类型，When 数据刷新，Then 只展示筛选后的用例，空态与错误态可恢复。

## 5. 技术考量

- 在 `/api/v1/auth/public-access` 提供无需登录的安全目录契约；菜单只含名称/路径/图标/层级，不含权限、用户或项目数据。
- 保留 `/test-cases/domains` 管理契约，新建静态 `/test-cases/taxonomy`，避免破坏分类管理；静态路由注册在 `/{case_id}` 前。
- taxonomy 采用兼容推断：运营后台优先、接口测试次之、用户端再次、无法判断归“其他”；不伪造或回写存量数据。
- 前端游客态由 `MainLayout` 阻止 `<Outlet>` 挂载；受保护模块点击统一进入一个登录 Dialog。
- React 异步请求使用 AbortSignal；游客态不得调用 `/system/menus`，登录态不得重复调用公开目录。
