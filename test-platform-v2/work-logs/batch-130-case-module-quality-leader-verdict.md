## Leader 抽检

- **真实模块优先**：`surface → domain → module_path` 是唯一产品层级；终端只作为覆盖标签。
- **同名模块歧义**：全量导入以 inventory 的 `用户端/运营后台` 为权威，裸“商城”“UGC”不能反向覆盖端别；审计错配为 0。
- **父子聚合**：模块父节点采用前缀匹配，选择“预测 Pick”会包含入口、异常恢复、权限异常等后代。
- **场景可见**：列表响应和表格同时输出真实 `positive_negative`，负向筛选单请求且分页 total 一致。
- **异常不是改标题凑数**：76 条 overlay 按 38 个模块的真实动作、依赖和业务不变量生成，步骤含故障注入、恢复/重试以及副作用断言。
- **导入安全**：重复模块局部 `TC-*` 通过稳定哈希 ID 命名；幂等只接受精确 case_id 命中，不再把无关 total 当作已存在。
- **数据完整性**：7,879 条均有唯一 ID、标题、前置、可执行步骤和预期；非 happy-path 3,896 条，占 49.45%。
- **浏览器证据**：用户端/后台分层、无终端节点、父级聚合、负向筛选和三视口均通过，console/page errors 为 0。
