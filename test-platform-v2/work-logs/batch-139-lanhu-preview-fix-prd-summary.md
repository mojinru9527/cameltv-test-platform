# Batch 139 — 蓝湖原型截图预览修复 PRD-lite
> **Product (🟦)** | Date: 2026-08-10 | Status: Approved

mode: light
豁免理由: 修复预览弹窗展示与截图 404 体验，纯前端（含 API 调用参数），无后端/接口/配置变更。

## 1. 问题陈述
1. 蓝湖原型图预览弹窗显示异常/变形；切换截图时报 404 "资产文件缺失"（全局弹错）。
2. 根因：资产截图文件在 Railway 部署重建后丢失（/app/storage 无持久卷），数据库资产记录仍在 → 下载 404；前端把 404 当普通错误全局 toast，且预览布局在加载失败时显破碎。
3. 期望：仅采集最新版本时，预览只展示最新版本涉及模块截图。

## 2. 成功指标
| 指标 | 基线 | 目标 | 测量窗口 |
|------|------|------|---------|
| 截图 404 体验 | 全局报错+占位破碎 | 静默（无全局 toast）+ 清晰提示"文件已失效，请重新采集" | 本批验收 |
| 弹窗布局 | 易变形 | 固定高度/宽度约束，md+ 左右分栏稳定，内容完整可滚动 | 本批验收 |
| 版本展示 | 仅版本号 | 预览标题显示版本信息 | 本批验收 |
| 回归 | - | 前端 444 无新增失败 | 本批验收 |

## 3. 非目标与 C 条件
- 不修后端资产存储持久化（Railway 卷/对象存储属部署项，单独处理，本批仅改善体验与提示）。
- 不改采集逻辑；仅最新版本采集已由 Batch 137 提供（资产天然只含最新版本页面）。

## 4. 用户故事与验收标准
- As 用户, I want 截图失效时不弹错、有清晰提示, so that 我知道需重新采集。
  - Given 资产文件已被部署重建清掉 / When 打开预览切换截图 / Then 无全局 404 toast，显示"截图文件已失效（部署重建存储后旧截图不可用，请重新采集）"。
- As 用户, I want 预览弹窗稳定不变形、内容完整, so that 截图与 OCR 都能看清。
  - Given 打开预览 / Then 弹窗固定高度、左右分栏、内容可滚动，不因截图失败破碎。

- 布局：DialogContent flex 列 + body min-h-0/md:h-[70vh]，左图 md:h-full、右 OCR ScrollArea。
