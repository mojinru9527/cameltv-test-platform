# Batch 144 — 蓝湖原型截图预览弹窗增强（截图放大 + OCR 与截图一一对应）
> **Product (🟦)** | Date: 2026-08-10 | Status: Approved

mode: light
豁免理由: 纯前端 UI 增强（预览弹窗布局/交互），无新接口/新依赖/后端变更。
非目标: 不修改 OCR/采集数据本身，不新增后端接口。

## 1. 问题陈述
用户反馈「蓝湖原型截图」预览弹窗（PrototypePreview）可读性差：
1. 截图区太小：弹窗 `max-w-[92vw]` 且 OCR 面板固定占 300px，截图被压缩、大图/图谱细节看不清（用户要求弹窗加宽到约 1200px 看效果）。
2. OCR 与截图不对应：右侧 OCR 是一大段长文本，没有明确标识「第几页/哪个页面」，看不出是哪张截图提取的，有用信息（交互说明）被淹没。
3. OCR 与截图切换必须双向一一对应：切换图片 → OCR 跟着切；在 OCR 侧切换页 → 图片也跟着切。

## 2. 成功指标
| 指标 | 基线 | 目标 | 测量窗口 |
|------|------|------|---------|
| 弹窗宽度 | 92vw（小屏被 OCR 挤压） | `min(1200px,96vw)`，截图区显著增大 | 本批验收 |
| OCR 面板可折叠 | 固定 300px 常驻 | 可显示/隐藏，隐藏后截图占满整宽 | 本批验收 |
| 双向联动 | 仅图片侧可翻页 | 图片侧翻页 + OCR 面板头部页切换均驱动同一 currentIndex，图/文同步 | 本批验收 |
| OCR 对应标识 | 无页面标识 | 面板头部「第 N/M 页 · 页面名 · 该页 OCR（n 字）」 | 本批验收 |
| 交互说明 | 埋在长文本后 | 独立醒目区块 | 本批验收 |
| 回归 | - | typecheck/build/vitest 全绿 | 本批验收 |

## 3. 用户故事与验收标准
- As 用户, I want 截图看得清, so that 能判断图谱/设计稿内容。
  - Given 打开预览弹窗 / Then 弹窗宽约 1200px，截图区占主体，OCR 可收起后截图占满整宽。
- As 用户, I want OCR 与截图一一对应, so that OCR 有意义。
  - Given 预览弹窗 / Then 切上一页/下一页（图片侧或 OCR 侧）时，图片与 OCR 同步切换；OCR 面板头部显示「第 N/M 页 · 页面名」。
- As 用户, I want 快速看清大图, so that 细节可辨。
  - Given 预览弹窗 / Then 提供「适应宽度」缩放 + 滚轮缩放/拖拽 + 重置；可一键打开原图新窗口。

## 4. 技术方案要点
- `PrototypePreview.tsx`：
  - DialogContent：`max-w-[92vw]` → `w-[min(1200px,96vw)] max-w-[96vw]`。
  - 新增 `showOcr` 状态 + 工具栏「显示/隐藏 OCR」按钮；grid 列在 `[minmax(0,1fr)_320px]` 与 `[minmax(0,1fr)]` 间切换；高度 `md:h-[70vh]` → `md:h-[74vh]`。
  - 图片与 OCR 共用 `currentIndex`（已存在），OCR 面板头部增加页切换（‹ 第 N/M 页 ›）按钮，双向驱动 `goTo`。
  - OCR 面板头部：`第 {n}/{m} 页 · {page_name}` + `OCR 提取文字（{chars} 字）` + 复制全文；交互说明独立成醒目区块。
  - 工具栏新增「适应宽度」（fit-width 缩放）+「查看原图」（新窗口打开 blob URL）。
- 验证：typecheck/build/vitest + 浏览器 1200px 实测双向联动。
