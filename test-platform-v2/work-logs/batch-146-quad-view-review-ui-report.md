# Batch 146 — 视角 1：资深 UI 设计工程师对抗性审查报告

> **审查人**：UI 设计工程师视角（batch-146 四视角审查）| 日期：2026-08-11 | 环境：生产 `https://cameltv-test-platform1.vercel.app/`
> **方法**：DOM/ARIA 树程序化审计（模型无图像输入，截图已存 `evidence/batch-146/` 供人工复核）+ 全页面交互走查 + UI 规范（`cameltv-ui-conventions`）逐项对照
> **范围**：31 路由 / 24 页面域全覆盖，含深色模式（黑曜主题为默认）、加载/空态/错误态、表单校验、响应式交互

---

## 1. 总体结论

**平台 UI 工程质量中等偏上，但存在三类系统性问题**：① 隐藏组件泄漏进可访问性树（全局，P2）；② 术语/口径不一致影响用户信任（覆盖率、用例总数、功能按钮）；③ 高密度信息布局缺乏信息架构引导（26 项导航无分组、表格全文直出）。**无 P0 级 UI 缺陷**；P2 共 8 项、P3 共 12 项。

| 维度 | 评分 | 说明 |
|------|:----:|------|
| 视觉一致性 | 4/5 | 5 主题 Token 体系完整（黑曜/水晶等），shadcn 语义类统一；无裸色阶漂移 |
| 信息架构 | 2.5/5 | 26 项导航单列无分组；「版本测试任务/发布批次/运维控制」入口混乱；两个覆盖率概念并存 |
| 交互反馈 | 4/5 | 加载态/空态/错误态/守卫确认框齐备；删除有确认；校验提示即时 |
| 可访问性 | 2.5/5 | Command Palette 泄漏 + 脑图 SVG 键盘不可达 + 隐藏控件进快照（批量问题） |
| 状态表达 | 3.5/5 | 中文状态标签大部分落地（草稿/启用/已完成），但图表轴仍残留英文 functional |

## 2. 问题清单（P0–P3）

### P2（明显缺陷/一致性）

| # | 位置 | 问题 | 证据 |
|---|------|------|------|
| UI-1 | 全局（所有页面） | **Command Palette 隐藏组件泄漏**：每个页面 ARIA 树含 `heading "Command Palette"` + `Search for a command to run...` 且 `isVisible()=true`，读屏用户与键盘导航被无关内容干扰；疑似某命令面板组件未正确 `hidden` | 全页面快照复现；`evidence/ui/mindmap-commandpalette.png` |
| UI-2 | 需求页 | 同一页面两个「覆盖率」概念并存（需求覆盖率 0% vs 交互覆盖率 0.0%），无标签区分，术语混淆 | 需求页快照 |
| UI-3 | 需求页 | 交互缺口列表条目长文本截断无省略号（`league_Brazilian Cu`），无 title 提示 | 缺口列表快照 |
| UI-4 | 追溯页 | 图表轴标签混用英文 `functional` 与中文「接口/功能」，违反 UI 规范「状态标签裸英文」红旗 | 追溯页图表 |
| UI-5 | 计划详情 | 「批量执行/开始执行/一键执行」三按钮并存且职责无区分说明，误触风险（本次审查误触发 325 条全量执行） | 计划详情快照 |
| UI-6 | 计划详情 | 行级「执行」=手动结果录入对话框，**执行结果默认「通过」**，与自动执行按钮并列无标识，误录通过风险高 | 执行用例对话框 |
| UI-7 | 用例服务 | 搜索框无「搜索受当前筛选影响」提示：选择「用户端」后搜接口域用例得 0 结果，易误判为搜索故障 | CRUD 实测 |
| UI-8 | 主题实验室/导航 | 主题切换能力（5 主题）全局可用，但「主题实验室」入口显示「实验功能未开放」占位，信息架构矛盾 | /theme-lab 快照 |

### P3（细节/打磨）

| # | 位置 | 问题 |
|---|------|------|
| UI-9 | 用例脑图 | 脑图为大 SVG，无键盘可聚焦节点，纯键盘用户不可达 |
| UI-10 | 未知路由 | 任意不存在路径显示「页面建设中」而非 404，无法区分「未建」与「地址错」 |
| UI-11 | 用例表格 | 每行直出前置/步骤/预期全文（高密度），跨屏阅读困难；建议折叠+展开 |
| UI-12 | 接口测试 | 快速调试 URL 拆 4 字段（服务器/服务/模块/路径），与「快速」语义冲突 |
| UI-13 | 工作台 | 图表段落「共 7879 条用例…」与图例数据冗余混排 |
| UI-14 | 侧边栏 | 26 项导航单列无分组/折叠，建议按「测试链路/质量运营/资产/管理」分组 |
| UI-15 | 定时任务 | 停用调度无「停用原因」提示，无法区分主动停用与故障停用 |
| UI-16 | 测试计划 | 「执行历史」列表无失败原因摘要列（只有执行方式备注） |

### 正面发现（保持）

- ✅ 运维发布控制未配置时降级提示清晰（batch-127 US-4 落地）
- ✅ 专项/报告/缺陷/数据集/通知 五处空态均带引导文案与 CTA
- ✅ 性能监控 SoloX 不可用时明确「不会生成模拟数据」
- ✅ 生产守卫确认框（读/写分类 + 影响范围 + 目标 Base URL）设计优秀
- ✅ 表单必填校验即时（标题/步骤/预期结果）、删除双确认
- ✅ 全局主题 Token 体系与深色模式完整，无裸色阶

## 3. 优化建议（按优先级）

1. **P0 批次**：修复 Command Palette 泄漏（全局 hidden/移除）；计划页三个执行按钮合并为「执行」+ 高级选项，手动录入默认值改「请选择」。
2. **P1 批次**：导航分组重构（5 组）；统一「覆盖率」术语与口径；截断文本统一省略号+title。
3. **P2 批次**：脑图键盘可达（节点 focusable + arrow 导航）；404 页区分；表格行折叠模式；快速调试支持「免断言裸发」模式（先看响应再写断言，见视角 2 API-01）。
