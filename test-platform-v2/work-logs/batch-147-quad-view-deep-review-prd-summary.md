## 3. 审查方法（对抗性，双 AI 交叉验证）

- **双 AI 独立走查**：两个子智能体分别按「UI+测试工程师」与「架构+甲方」分组独立走查全部模块，随后交叉核对发现清单，去重、补漏、标冲突。
- **每个模块执行操作基线**：列表-详情-筛选-分页-搜索-创建-编辑-删除-错误路径-空态-边界 ≥10 项；写路径使用明确标记的临时数据（前缀 `B147TMP-`）并在报告登记清理状态。
- **生产网络面板全程记录**：重复请求、N+1、冗余拉取、未缓存、轮询。
- **146 复查**：对 146 报告 35 项发现逐条在生产复测，标注「已修复/仍存在/无法复测/新发现」。
- **评分**：每个模块按五维（功能完整/易用性/一致性/性能/价值密度）1–5 分。
- **证据**：截图 + DOM/ARIA 快照 + Network 捕获 JSON + 交互 JSONL，入 `work-logs/evidence/batch-147/`。
