## 1. 问题陈述

1. **无用功能移除**：专项测试、性能监控对当前体育平台项目无用，要求代码注释+界面隐藏（第 1 条）。
2. **价值存疑**：对测试数据集/Agent 工作台/蓝湖证据包/目标环境/版本测试任务/报告中心/集成配置/通知配置 8 个功能是否真的提升效率存疑，并要求对全平台做冗余度评估（第 2/3 条 + 追加要求）。
3. **功能缺陷**：知识中心 tab 错位/不切换（第 6 条）；接口测试资产列表只显示 3 个服务+45 页分页、请求参数为空、接口用例不能改参数/加断言（第 7 条）；UI 自动化只有任务列表，没有用例与运行过程展示（第 8 条）。

## 4. 技术考量
- 菜单由后端 `menu_service.menu_tree` 从权限表构建：隐藏需在服务层过滤 `menu:special`/`menu:perftest`（存量库立即生效）+ seed.py 注释（新库不再生成）+ 前端路由/命令面板/访客目录注释。
- 接口资产分页：`AssetTab` 按接口 20 条/页拉取后按 服务→模块→路径 分组展示，导致一页只有 3 个服务组；改为"按服务分页"（每页 20 个服务）或列表增加服务名列。倾向：保留分组，但**分页改为按服务分组后整体分页**，避免单页 3 组。
- 接口用例编辑：复用 `pages/testcase/CaseDrawer.tsx`（已支持 api 类型 + 接口数据 tab + 断言 JSON 编辑），在 `ApiCaseTab` 加"编辑"按钮打开 CaseDrawer。
- UI 自动化：`uitest/index.tsx` 已有运行详情/产物/轮询，本次增加"用例/脚本"数据源展示（fetchScripts + fetchTestCases(case_type=ui)）与最近运行概览。
- 知识中心 tab：修复 `setSearchParams` 丢失参数/聚焦问题 + tab 容器滚动/换行样式，具体以复现结果为准。
