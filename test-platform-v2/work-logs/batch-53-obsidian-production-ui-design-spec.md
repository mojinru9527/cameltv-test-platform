# Batch 53 — 黑曜流界生产级 UI Design Spec

> Design | Date: 2026-07-28 | Target score: 100/100

## 设计目标

Batch 53 不改变黑曜流界的品牌方向，而是把它从“主题展示完成”提升到“真实生产任务完成”：

- 保留黑曜、翡翠操作色、克制玻璃和高密度专业工具气质。
- 数据可读性、可访问性和任务效率优先于装饰动效。
- 同一页面在 390、768、1440 三档下保持同一任务语义，不通过简单缩小桌面布局解决移动端。
- 共享组件规则成为后续五套主题的统一生产标准。

## 信息层级

每页保持四层：

1. 页面身份：单一 H1、短说明、唯一主操作。
2. 状态摘要：只保留一套 KPI；工作台 Hero 与统计卡不得重复。
3. 查询与批量操作：筛选、搜索、列设置、批量动作形成独立工具条。
4. 数据/任务区：表格、图表、画布、表单；loading/empty/error 不改变区域主要尺寸。

## 响应式契约

### 390px

- 页面内边距 12–16px。
- 操作条允许分组换行；主操作优先，低频动作进入更多菜单。
- 所有触控操作有效热区 ≥44px。
- 表格采用“局部滚动 + 关键字段优先 + 行操作可发现”策略，不允许页面整体横向滚动。
- 图表单列铺满；减少刻度，不删除单位和关键信息；附数据摘要。
- 多面板专业工作区切为分段/抽屉/纵向布局。

### 768px

- 保留紧凑双列或主从布局；工具条可换行但不遮挡。
- 图表至少 320px 有效绘图区。
- 表格可局部横向滚动，操作列保持可发现。

### 1440px

- 使用统一 `max-width`，避免内容无限拉伸。
- 高密度表格和工作区可使用多列；主次面板宽度明确。
- 不重复移动端已折叠的信息。

## 组件契约

### Button / IconButton

- 可见尺寸可以紧凑，但 coarse pointer 命中区 ≥44px。
- 图标按钮必须有 `aria-label`；loading 时保留原名称并声明 `aria-busy`。
- disabled、pressed、focus-visible、hover 状态均可区分。
- 破坏性动作使用 danger 语义，并与普通动作空间分离。

### DataTable

- 外层只负责卡片边界；内层滚动容器具有 `tabIndex=0`、可访问名称和边缘提示。
- 排序头维持 `aria-sort`。
- 移动端优先保留名称、状态、优先级和操作；次要列允许通过列设置查看。
- 分页使用完整中文可访问名称，按钮不小于 44px。
- 空状态包含清除筛选/创建动作；错误状态包含重试。

### Chart

- 必须包含标题、说明、单位、图例、关键结论。
- 提供结构化数据表或屏幕阅读器摘要。
- 移动端减少刻度而不是压缩字体；交互不依赖 hover。
- 动画尊重 reduced-motion；数据第一帧可读。

### Form

- Label 与字段程序化关联；复杂字段有持久 helper text。
- 错误紧邻字段并通过 `aria-describedby` 关联；多错误时聚焦首错。
- 提交中禁用重复提交，成功/失败均给出明确下一步。

### Navigation

- 当前页 `aria-current="page"`。
- 移动抽屉选择目标后关闭；Escape、遮罩、关闭按钮均可退出。
- 路由切换后焦点进入主内容；菜单失败在原位置提供重试。

## 黑曜视觉约束

- 画布、卡片、弹层使用已有语义令牌，不在页面组件新增 hex/rgb。
- 玻璃只用于顶部导航、抽屉/检查器和需要表达层级的覆盖层。
- 业务正文不低于 12px；移动端主体默认 14–16px。
- 状态颜色同时配合图标、文字或形状。
- 动效 150–300ms，只使用 transform/opacity；reduced-motion 下关闭非必要动效。
