## 审计结论

Batch 52 已完成主题状态统一、首屏主题、黑曜语义令牌和轻数据代表页回归，但尚未达到“生产级满分”：

- 既有 41 项 Playwright 回归全部通过，覆盖重点是空数据或轻数据页面，不覆盖高密度真实业务状态。
- 黑曜主题在空状态下无全局横向溢出，但用例表格、工作台图表及多个专业工作区在 390px 下仍存在可用性问题。
- 共享组件仍允许 22–36px 的图标按钮和 10–11px 的业务文字；黑曜主题的 44px 规则只覆盖 `.ui-btn*`，没有覆盖全部生产按钮。
- 图表和部分图标操作缺少完整的键盘、文本替代与可访问名称。
- 其他五套主题的主要问题同时记录，但不在 Batch 53 做全面视觉重制；后续批次必须复用本台账和评分矩阵逐套验收。

## 问题清单

### P0 — 发布阻断

#### UI53-P0-01：缺少真实后端生产数据 E2E

- 页面：工作台、用例管理，后续扩展到表单和专业工作区。
- 现象：Batch 51/52 浏览器用例主要使用路由 mock；无法证明认证、项目头、真实分页、真实错误和接口竞态下的 UI 行为。
- 风险：空状态通过会掩盖表格溢出、操作按钮缺名、图表压缩、重复请求及字段兼容问题。
- Batch 53 验收：
  - 至少 1 条不 mock `/api/v1/**` 的真实后端 E2E。
  - 通过 API/测试种子创建 ≥24 条用例和完整工作台统计。
  - 浏览器可完成登录/项目选择或等价真实认证引导，页面无未处理请求错误。
  - 每次用户动作只产生 1 个有效 GET，旧响应不能覆盖新筛选条件。

### P1 — 必须在 Batch 53 关闭

#### UI53-P1-01：图标按钮缺少可访问名称

- 重点页面：`testcase`、`testplan`、`knowledge`、`release-bundles`、`special`、`uitest`。
- 证据：高密度用例状态曾出现 61 个 `button-name` 严重节点、41 个无名交互节点。
- 修复原则：图标按钮必须显式 `aria-label`；装饰图标 `aria-hidden`；不能依赖 hover 或只依赖 `title`。
- 验收：生产数据页面 Axe WCAG A/AA 为 0；`button:not([aria-label])` 仅允许含可见文本的按钮。

#### UI53-P1-02：移动端触控目标不足

- 现象：用例页生产数据状态下，49 个业务/表格操作中 45 个小于 44px；原子尺寸仍允许 22/28/32/36px。
- 根因：黑曜 coarse-pointer 规则只覆盖 `.ui-btn*`，shadcn Button、原生 button、Checkbox、分页和下拉项未纳入。
- 验收：390px + coarse pointer 下所有主要 button、input、select、checkbox、分页和菜单项有效热区 ≥44×44px；相邻热区间隔 ≥8px 或有足够命中区。

#### UI53-P1-03：高密度 DataTable 移动端不可完成任务

- 现象：约 1221px 表格被放入 350px 视口；行尾操作不可见；分页被拆散。
- 根因：表格容器无明确的局部滚动边界/提示，也没有移动端优先字段和操作策略。
- 验收：
  - 页面自身 `scrollWidth - clientWidth ≤ 1`。
  - 表格局部可滚动，左侧关键字段或移动摘要保持可识别，滚动容器有可访问名称和键盘焦点。
  - 行操作在 390px 下无需精确拖动到最右端才能发现；分页可单行或合理换行。

#### UI53-P1-04：工作台移动图表压缩与信息重复

- 现象：390px 下柱状图有效宽度约 188px，图例换行、X 轴标签丢失；Hero 指标与统计卡重复显示。
- 验收：移动端只保留一套 KPI 层级；图表宽度使用完整内容区，轴标签不截断；图表旁提供可读数据摘要或表格替代。

#### UI53-P1-05：专业工作区固定尺寸破坏响应式

- 文件：
  - `pages/knowledge/components/GraphTab.tsx`
  - `pages/knowledge/components/SphereTab.tsx`
  - `pages/release-bundles/VersionPanorama.tsx`
  - `pages/release-bundles/components/InteractionAnnotator.tsx`
  - `pages/apitest/components/DebugTab.tsx`
- 验收：390/768/1440 下不产生页面级溢出；控制区优先于次要信息；画布/面板可缩放或在明确局部区域滚动；关闭、返回、保存可触达。

#### UI53-P1-06：图表缺少键盘与文本替代

- 现象：约 10 个生产图表只提供视觉图形/hover tooltip。
- 验收：每张核心图表有标题、摘要、单位、图例和隐藏/可见数据表；交互图形可键盘访问，或提供等价筛选/查看数据入口；不以颜色作为唯一含义。

#### UI53-P1-07：表单错误反馈不完整

- 重点：集成配置及复杂抽屉表单。
- 现象：存在校验逻辑但缺少字段旁错误、`aria-invalid`、错误关联和首错聚焦。
- 验收：可见 Label；失焦或提交后显示字段旁错误；错误说明原因和修复方式；提交按钮 loading/disabled；首个错误获得焦点。

#### UI53-P1-08：移动导航语义与关闭行为不完整

- 现象：当前项缺少 `aria-current`；抽屉导航后可能不关闭；菜单加载失败主要依赖 toast。
- 验收：当前项可见且有 `aria-current="page"`；选择目标后移动抽屉关闭并恢复合理焦点；加载失败在导航区域内提供重试。

#### UI53-P1-09：异步 effect 缺少统一取消和竞态保护

- 证据：约 32 个文件、43 个异步 effect 未统一清理；约 14 处空 `catch`。
- 验收：Batch 53 触及的页面全部使用 AbortController/cancelled 标志；切换筛选时旧响应不能覆盖新状态；错误不得静默吞掉。

### P2 — 本批尽量关闭，未关闭必须有明确后续批次

4. `UI53-P2-04`：高密度 DataTable 没有 50+ 行性能/虚拟化或分页压力测试。
5. `UI53-P2-05`：加载主要依赖旋转图标；超过 300ms 的数据区优先 skeleton，并保留区域尺寸。

## 统一满分门禁

1. Axe WCAG A/AA：0 violation；无无名操作。
2. 390×844、768×1024、1440×900：页面级横向溢出 ≤1px。
3. coarse pointer：核心交互目标 ≥44×44px。
4. 真实数据：工作台 + 表格 + 图表 + 表单 + 导航 + 覆盖层均覆盖非空、加载、空、错误状态。
5. 网络：每次操作 1 个有效 GET；无 stale response；无未处理失败。
6. 运行时：console error、page error、失败请求均为 0（显式断言的错误态除外）。
7. 视觉：无重复 KPI、无 9–11px 业务正文、无颜色唯一表达、无主题外硬编码关键色。
8. 工程：typecheck/build/Vitest/相关 Playwright/全量回归全部通过。
