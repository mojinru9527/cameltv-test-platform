# Batch 53 — 黑曜流界生产级 UI PM Plan

> PM | Date: 2026-07-28 | Workflow: Agent Team / Codex

## 交付边界

- 本批修复：黑曜主题、共享 UI 基元、工作台、用例管理、移动导航及已明确的专业工作区响应式阻断。
- 本批记录但不全面重制：Cyberpunk、Apple、Clay、X-Lab、Liquid Glass。
- 不新增产品功能，不改后端业务模型；只允许为真实 E2E 增加测试种子/测试辅助。

## 用户故事

### US-1：真实数据下完成核心任务

作为测试负责人，我可以在手机、平板和桌面查看工作台、筛选用例、读取状态并执行行操作，不会因为表格、图表或操作按钮被挤出屏幕而中断。

### US-2：键盘和辅助技术完整操作

作为键盘或屏幕阅读器用户，我可以识别每个按钮、当前导航、表格排序、图表结论和表单错误，并在弹层关闭后回到原位置。

### US-3：稳定、可恢复的反馈

作为弱网用户，我能看到稳定 loading 区域、明确错误和重试动作；快速切换筛选不会被旧响应覆盖。

## 执行切片

1. 先写失败测试：真实数据用例页、44px、Axe、DataTable 局部滚动、工作台图表摘要。
2. 修共享基元：Button、Checkbox、Pagination、DataTable、ChartA11y 辅助结构。
3. 修壳层与导航：`aria-current`、移动抽屉关闭、导航错误重试、路由焦点。
4. 修工作台：去重 KPI、移动图表、摘要/数据表、空/错/加载。
5. 修用例页：筛选工具条、移动表格/行操作、图标名称、请求竞态。
6. 修专业工作区：Graph/Sphere/Panorama/Annotator/Debug 三档布局。
7. 全量验收：真实后端、三档视口、Axe、网络、console、typecheck/build/Vitest/Playwright。

## 完成定义

- 问题台账 P0/P1 全部关闭。
- 100 分矩阵每项有自动化或可复现人工证据。
- 无新增硬编码密钥、调试输出、数据库或临时文件。
- QA Report 记录命令、退出码、失败集合、截图位置和残余 P2/P3。
- Leader Verdict 只有在硬门禁全部满足时才可为 GO。
