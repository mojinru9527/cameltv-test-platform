## 2. 环境与数据基线

- 分支：`feature/batch-53-obsidian-production-ui`
- 基线：`origin/main@4f9f807`
- 前端：`http://127.0.0.1:5177`
- 后端：`http://127.0.0.1:8004`
- 数据库：Batch 53 worktree 独立 SQLite，禁止提交数据库文件。
- 主题：`obsidian-flow`，dark only。
- 视口：390×844、768×1024、1440×900；移动用例启用 coarse pointer/touch。
- 数据集：
  - 工作台：完整 KPI、至少 6 个分类、至少 5 个优先级/状态点。
  - 用例：≥24 条，包含超长中英文名称、空字段、各优先级/状态、跨两页。
  - 错误：401/403/404/500/超时/旧响应后到。
