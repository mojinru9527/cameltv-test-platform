## 1. 问题陈述

batch-74 J16 实测发现：`ffmpeg_service._extract_bitrate` 对 HLS 流返回 `format.bit_rate`，
而该值是 **m3u8 播放列表**的码率（实测 24bps → 0.02kbps），并非媒体真实码率
（实测 HLS 视频流 `streams[].bit_rate` 为空）。导致「码率」指标恒误报不达标（C74-1）。
本批修复口径：优先媒体流 bit_rate → HLS 场景按分段大小/时长实测 → 非 HLS 兜底 format.bit_rate；
并用世界杯决赛回放 HLS 复测六项指标。
