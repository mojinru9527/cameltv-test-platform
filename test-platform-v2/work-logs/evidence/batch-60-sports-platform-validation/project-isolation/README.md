后端项目隔离阻止了实际误删，但 UI 显示上下文与请求 Header 已经错位。该问题必须在所有项目作用域页面复测，包括已打开编辑弹窗、批量选择、详情/子资源和后台任务。

修复方式：在主布局内以当前项目 ID 作为项目作用域边界键。项目变化时销毁旧页面子树并重新挂载当前路由，使旧列表、选择项、弹窗和本地草稿先清空，再由新项目上下文重新请求数据。

行为回归：`src/layouts/__tests__/ProjectScopeBoundary.test.tsx` 先复现项目 A 草稿残留，修复后验证项目切换会重新挂载并清空本地状态。
