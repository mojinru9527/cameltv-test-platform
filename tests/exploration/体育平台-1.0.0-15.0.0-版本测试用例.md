# CamelTv 体育平台 1.0.0 ~ 15.0.0 各版本测试用例

> 版本来源：蓝湖「用户端原型」更新日志（1.0.0-15.0.0，2024-05-07 至 2026-07-20）
> 用例设计：资深测试工程师（需求层面 + 用户操作/交互层面）
> 优先级：P0（核心必测）→ P1（常用）→ P2（一般）→ P3（边缘）
> 说明：版本之间为迭代优化关系；每个版本列出「需求变更点 + 对应测试用例」。已有线上实测结论见 `camel1tv-线上站点探索报告与测试方案.md`；16.0.0 单独成文见 `体育平台-16.0.0-测试用例.md`；融合版见 `体育平台-最终测试用例.md`。

---

## 使用说明

1. **版本演进关系**：后续版本包含前序版本全部功能。回归测试时以「本版本变更点 + 前序关键功能」为范围。
2. **用例编号**：`TC{版本号去点}-{模块}-{序号}`，如 `TC110-LIVE-001` = 1.1.0 直播模块第 1 条。
3. **交互用例**：标注 `[交互]` 的用例聚焦用户操作路径、反馈、状态一致性。
