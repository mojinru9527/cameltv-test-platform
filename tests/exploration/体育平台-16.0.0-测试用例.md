## 一、版本概述

**16.0.0 核心主题：新增体育项目「篮球」及相关多项目适配**

| 变更域 | 变更点 |
|--------|--------|
| 首页 | 新增"体育项目"入口 TAB（Football / Basketball） |
| 赛事详情页 | 赛况 TAB 按体育项目差异化展示数据指标；进行中比赛时间按体育项目差异化展示；篮球不展示"阵容"TAB、新增"Box Score"球员数据统计 TAB；数据 TAB 按体育项目差异化展示 |
| 联赛模块 | 移除"Round"TAB，新增"交易"TAB，合并"球员数据"及"球队数据"TAB；排名/数据/比赛 TAB 按体育项目差异化查询展示 |
| 球队模块 | 调整"比赛"TAB 查询逻辑；排名/数据/交易 同联赛模块调整 |
| 球员模块 | "赛季数据"TAB 按体育项目差异化查询展示 |
| 搜索 | 新增选择"体育项目"功能，按体育项目分别搜索 |
| 资讯 | 资讯分类及资讯新增"体育项目"配置；资讯列表及详情新增"体育项目"筛选 TAB |
| 广告 | 广告活动新增"体育项目"配置；首页及赛事详情仅展示当前体育项目配置的广告 |
| 比赛回放 | 赛事回放新增"体育项目"配置；回放列表新增"体育项目"筛选 TAB |
| 后台配置 | 热门比赛/热门联赛/热门球队/热门球员新增"体育项目"配置 |

**涉及原型页面**：首页、赛况、赛况(篮球)、球员数据统计(Box Score)、数据、联赛详情页(排名/数据/交易)、球队详情页(排名/数据/交易)、球员详情页(数据统计)、搜索页、搜索结果页、资讯列表、资讯详情、赛事回放列表(MB)、赛事回放详情(MB)、赛事回放列表(PC)、赛事回放详情(PC)
