## 一、登录接口契约（实测确认）

```http
POST https://api.cameltv.live/account-service/ee/client/demo/login
Content-Type: application/x-www-form-urlencoded
countryCode=86&mobile=18476944071&password=<测试账号密码>
```

成功响应：

```json
{"status":200,"data":{"nickname":"sex 1235","mobile":"+86 18476944071",
  "userId":"11025728","token":"<32位hex>","userSig":"C_7936...","avatar":"..."}}
```

### 关键结论
1. **仅接受 form-urlencoded**（JSON 请求体被拒，返回业务 400）
2. **AccessToken = userSig**（`C_...` 值风格）；经 `Authorization`（裸/Bearer）、`token` 头或 `auth` Cookie 携带
3. **`uid` 头传 userId 会破坏鉴权**（实测 `uid=11025728 + Authorization=userSig` → Invalid AccessToken）
4. 站点鉴权模型：`auth` Cookie = `{token: userSig, userId, userSig}`（来自 chunk `useCookies(["auth"])` 反编译确认）
5. 登录失败返回：`{"status":400,"msg":"The phone number is not registered"}`（错误国家码时）
