# 跨平台交互测试 Profile

本文件将通用交互准则映射到不同平台。只选择项目真实支持的平台；平台指南是适配依据，不得把某一端的行为无条件套到其他端。

## 1. Web / 移动 Web

- 视口：桌面/平板/手机关键断点、窄屏、横竖屏、缩放、浏览器字体放大。
- 页面：刷新、直接访问路由、深链接、浏览器前进/后退、多个标签页、打开/关闭窗口。
- 输入：键盘 Tab/Shift+Tab/Enter/Space/Escape/方向键；IME、粘贴、自动填充、密码管理器。
- 滚动：页面滚动与容器滚动、固定头尾、弹窗滚动、焦点元素被遮挡、滚动位置恢复。
- 资源：图片裁切、srcset/响应式资源、字体、SVG、视频、下载文件、缓存和失效 URL。
- 浏览器：目标支持版本的 Chrome/Edge/Firefox/Safari；私密模式、禁用第三方 Cookie 或受限存储（若业务要求）。
- 可访问性：按项目目标验证 WCAG 2.2；自动扫描不能替代键盘、读屏和人工判断。

## 2. 小程序

- 生命周期：首次进入、onShow/onHide、切后台/前台、页面栈、进程销毁后重进。
- 导航：页面跳转/重定向/返回/Tab 切换/分享路径/扫码进入/授权回跳。
- 平台接口：登录、支付、分享、扫码、定位、相册/相机、订阅消息等权限提示及拒绝/撤回路径（仅测试使用到的接口）。
- 设备：不同厂商机型、系统版本、状态栏/安全区域、软键盘、刘海/圆角、横竖屏。
- 网络：弱网、断网、重连、请求取消、后台恢复后重复请求。
- WebView/原生组件混合：滚动冲突、焦点、键盘、返回手势、媒体播放和页面通信。
- 版本差异：基础库、平台审核/发布版本、灰度策略、旧版本兼容。

## 3. iOS / Android 原生 App

- 生命周期：启动、恢复、后台、挂起、杀进程、重启、升级安装、卸载重装。
- 系统交互：权限弹窗、系统分享、文件选择、相机、通知、系统返回/边缘返回、键盘。
- 手势：滑动返回、长按、拖拽、双指缩放、多点触控、手势冲突和可替代操作。
- 显示：安全区域、动态字体、显示缩放、深浅色、高对比度、分屏/多窗口（适用时）。
- 设备能力：摄像头、麦克风、蓝牙、定位、NFC、生物识别、传感器及权限变更（适用时）。
- 兼容：OS 版本、屏幕规格、厂商系统、低内存和后台限制；覆盖矩阵由用户分布和风险确定。
- 发布：App 升级后本地草稿、登录态、数据库迁移、深链接和推送行为。

## 4. Windows / macOS / Linux 桌面客户端及 PC 软件

- 窗口：最大化/还原/最小化、自由缩放、最小尺寸、多屏、DPI、不同缩放比例。
- 输入：键盘快捷键、菜单快捷键、Tab 焦点、鼠标右键、中键、滚轮、触控板、触摸屏（适用时）。
- 文件：系统文件选择器、拖放、路径权限、长路径、中文/空格/特殊字符文件名、文件占用、磁盘空间不足。
- 多实例：重复启动、多窗口、单实例锁、多个用户/系统账户、崩溃恢复。
- 系统集成：通知、托盘、系统菜单、剪贴板、默认浏览器、协议 URL、自动更新、卸载残留。
- 显示：高 DPI、字体、深浅色、系统缩放、远程桌面、虚拟机。

## 5. 硬件 / 嵌入式 / IoT

先建立输入—状态—输出映射，而不是套用网页控件检查：

- 输入：物理按钮、旋钮、触摸面板、遥控器、语音、扫码、传感器、外部接口。
- 状态：待机、启动、运行、忙碌、错误、低电量、断网、配对、升级、恢复出厂等实际定义状态。
- 输出：屏幕、LED 颜色/闪烁、蜂鸣器、扬声器、震动、机械动作、继电器/执行器。
- 映射：动作含义、短按/长按/双击、旋转方向、按键组合、动作优先级。
- 时间：输入去抖、反馈时延、长按阈值、超时、重复触发、事件乱序。
- 环境：电源波动、断电重启、网络切换、蓝牙断连、温度/光照/噪声/振动等产品工作条件。
- 安全：误触保护、急停/锁定/安全状态、恢复步骤和告警。涉及医疗/汽车/工业/航空等受监管领域时，必须额外应用该行业适用的安全/可用性标准与合规流程。
- 物理观察：按压力度/手感、按钮标识、状态灯可视角度、声音可辨识、屏幕可读性；主观项应使用明确评价方案，不得伪装成纯客观断言。

## 6. 跨平台差异分类

对同一个业务动作，记录：

- `shared_behavior`：所有平台都必须相同的业务结果。
- `platform_specific_behavior`：因操作系统/平台约定而不同的交互方式。
- `unsupported_behavior`：某平台明确不支持的能力。
- `unknown_behavior`：未定义，需产品确认。

测试必须比较业务语义一致性，不要求所有平台 UI 外观/手势完全一致。
