# 接口用例必填真实数据（真实参数）规范

> **生效日期：2026-08-26 起。** 本规范为测试平台接口测试/接口用例的**强制要求**，
> 与 [API接口测试方案.md](./API接口测试方案.md) 并用；规则冲突时以本规范为准。

## 一、核心原则

> **凡提交接口测试/接口用例，必须使用真实数据（真实参数），禁止空参、假参数、占位值（如 `ttt`、`xxx`）、`1` 等无意义值导致接口返回空壳/业务 400。**

### 判据：用例的 `api_endpoint` 必须能通过**真实执行**返回真实数据

| 级别 | 判定 | 说明 |
|------|------|------|
| ✅ 真实数据 | 接口用真实 id/参数执行后返回真实数据（赛事/球队/球员/记录等非空且有业务内容） | 用例成立 |
| ⚠️ 空壳 | 空参/假参 → 业务 400 或 `data=null`/`[]` | **不合规**，须改为真实参数 |
| ❌ 假数据 | `?xxx=ttt`、占位符、无意义值 | **禁止** |

## 二、真实数据的来源

真实参数必须来自**被测系统真实数据源**，优先顺序：

1. **被测环境数据库**（MySQL/PostgreSQL）—— 从对应表读取真实 `id`/主键（如 `match_id`、`season_id`、`team_id`、`competition_id`、`player_id`）
2. **上游基础接口** —— 从 `home_match`/`hot_match`/`list_competition` 等列表接口的真实响应中提取 id/名称
3. **已验证的业务数据** —— 复用上一轮真实执行返回的真实记录 id

> ⚠️ 禁止从代码/示例/人为构造中硬编码 id，除非该 id 是跨环境稳定的真实业务主键。

## 三、用例必须满足的字段

| 字段 | 要求 |
|------|------|
| `api_endpoint` | 完整路径 + **真实 query 参数**（如 `/camel-service/ee/sports_live/home_match?day=20260825`、`/basketball-service/ee/sports_live/season_teams?seasonId=z318q6ntvwdmo9j`） |
| `api_assertions` | 必须含：HTTP 2xx + 响应时间 + **业务码断言**（`$.status == 200`）+ **数据存在断言**（`field data exists` / `records` 非空，有真实数据时） |
| `api_headers` | 必填 header（如 `Content-Type`、认证 token 引用） |
| `last_response_json` | 回填**真实执行响应**（非模拟/占位） |
| `last_run_status` | 真实执行结果（passed/failed），以真实执行为准 |

## 四、服务前缀（网关路由）

接口用例的 `api_endpoint` 必须带**服务前缀**，以目标环境网关实际路由为准：

- `camel-service` 服务 → `/camel-service/ee/...`
- `basketball-service` 服务 → `/basketball-service/ee/...`（篮球接口**必须**带此前缀，否则网关 404）
- 生产/测试5 网关各自前缀可能不同，执行前先验证前缀正确性

## 五、Checklist（提交接口用例前逐项自查）

- [ ] api_endpoint 带真实 query 参数（非空参/`ttt`/占位）
- [ ] 真实参数来自被测环境数据库或已验证的真实接口响应
- [ ] 接口真实执行返回**真实数据**（非 data=null / 空列表 / 业务 400）
- [ ] 断言含 HTTP 2xx + 业务码 + （有数据时）数据存在断言
- [ ] last_response_json 为真实响应
- [ ] 已带正确的服务前缀（网关路由可达）

## 六、执行与验证

1. 创建用例后，先做 **1 次真实执行** 验证返回真实数据（失败则回填真实参数重试）
2. 执行通过后回填 `last_response_json`（真实响应）+ `last_run_status`
3. 提交到测试计划前，确认用例为"真实数据版"

## 七、例外

- **负向/越权/缺参用例**：这些用例**故意**用异常/缺参入参，用于验证后端健壮性 —— 它们不要求返回业务数据，但**必须有明确的负向断言**（如预期 400/401/403），且不得与正向用例混用真实数据语义。
- 无参接口（如 `v5/matches`、`group_competition`、`hot-players`）：本身无需入参，用例直接调用并校验数据存在即可，不视为"空参"。
