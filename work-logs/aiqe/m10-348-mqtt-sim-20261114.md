# M10-348：模拟 MQTT broker 契约验证（2026-11-14）

> **结论**：用户选择"模拟 broker 契约验证"。已用内置最小 MQTT 3.1.1 broker + paho 模拟设备，
> 验证 `IotDriver` 的真实 MQTT 遥测读取、只读守卫与断连恢复；**无实机**。

## 1. 方案

`scripts/qa/mqtt_sim_verify.py`（自包含，无外部 broker）：

| 组件 | 说明 |
|------|------|
| MiniBroker | 127.0.0.1:18883，支持 CONNECT/SUBSCRIBE/PUBLISH/PING/DISCONNECT（QoS0） |
| FakeDevice | paho 模拟设备：订阅 `aiqe/device/cmd`，收到命令后向 `aiqe/device/telemetry` 发布遥测 |
| MqttTransport | paho 订阅遥测，发布命令并等待响应（2s 超时） |
| IotDriver | 既有适配器，验证只读守卫 |

## 2. 结果

```json
{
  "telemetry": {"op": "telemetry", "value": 42, "unit": "rpm"},
  "readonly_guard": "OK: IoT 默认只读，禁止操作: write",
  "disconnect": "OK: 遥测超时（broker 不可达或设备未响应）",
  "reconnect": {"op": "telemetry", "value": 42, "unit": "rpm"}
}
```

| 验收项 | 结果 |
|--------|------|
| 遥测只读读取（真实 MQTT 协议） | ✅ value=42 |
| 写操作拒绝 | ✅ `PermissionError` |
| 断连检测 | ✅ 超时（broker 停止） |
| 恢复后读取 | ✅（设备/驱动重连后 value=42） |

## 3. 边界

- **不是实机**：broker 与设备均为本地模拟；满足"契约验证"，不满足"实机验收"；
- 未引入生产依赖：paho 仅在验证脚本中按需使用（本地/容器安装），后端 requirements 不变；
- 真实 MQTT 设备接入时，把 `MQTT_HOST/PORT/凭据` 注入 transport 即可复用 IotDriver 语义。

## 4. 复跑

```bash
python -m pip install paho-mqtt
python scripts/qa/mqtt_sim_verify.py     # exit 0 = 全部通过
```
