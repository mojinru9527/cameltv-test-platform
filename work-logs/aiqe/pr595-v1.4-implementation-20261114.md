## 3. 关键行为变化（Reviewer 必看）

### 3.1 HTTP 200 ≠ PASS

`node_executor._execute_http` 只把请求完成视为 `SUCCEEDED`，业务 PASS 由 `AssertionRuntime` 判定：

- `assertions[]` 存在 → 逐条执行；
- 只有 legacy `expected_status` → 合成一条 `http_status` 断言；
- 断言缺失/无法评估 → `NOT_EVALUATED`，节点 `BLOCKED`，Run 不会 PASS。

### 3.2 Playwright probe

- 默认 `click` 是真实 `locator.click`；
- `probe_actionability` 只 `wait_for(visible)`，`dispatched=false`；
- `probe_only=true` 的 DriverResult 在 Assertion Runtime 中全部 `NOT_EVALUATED`，节点最多 `BLOCKED`。

### 3.3 Regression

- 必须提供 `previous_run_id` 且有冻结 Workflow 快照（或可加载的原 Workflow）；
- 必须 `deployed_sha` 与 `fixed_sha` 匹配，否则新 Run `BLOCKED`（不执行）；
- 通过 `launch_run` 创建 NodeRun/ExecutionJob，Run `RUNNING`；
- 旧 Run 只读不变；
- 没有快照时创建 `BLOCKED` Run，不再创建 `QUEUED` 假启动。

### 3.4 Quality Gate

`POST /api/v1/aiqe/admin/quality-gate` 只接受：

```json
{"run_ids": ["..."], "version_task_id": 123, "build_ref": "...", "environment_ref": "..."}
```

服务端从 `RunAssertionResult(severity=P0)` 计算，写入 `aiqe_quality_gate_snapshots`；历史快照不可更新。

### 3.5 生产执行

- `POST /api/v1/aiqe/runs` 在 `Environment.is_production=true` 或 `ENVIRONMENT=production` 时默认 403；
- 打开需 `AIQE_PROD_RUN_CREATE_ENABLED=true`，并另行审批；
- `AIQE_INPROCESS_EXECUTOR_ENABLED` 只执行 http/db，浏览器/设备仍必须外部 Runner；
- Reconciler 定时收敛，不把悬挂 Run 当成 PASS。

## 5. 已知限制（不得当成已完成）

1. **真实 Dogfood 未在本分支生产执行**：v1.4 的单测/集成测试证明代码接缝，但 M2 的六节点混合流程仍需 Test 环境真实 Node/浏览器/DB 的 Run ID 证据。
2. **JSONPath 为内置严格子集**，不支持过滤器/切片/函数；需要复杂 JSONPath 的场景必须先扩展并加测试，不能静默返回空。
3. **Trace 二进制未做内容级脱敏**：只做已知 secret 字节扫描 + 元数据；若扫描命中则不落库。需要更强保证时应在 Runner 侧生成前脱敏。
4. **外部 Runner 证据上传**：`aiqe_local_runner.py` 会上传文件到 `execution-jobs/{id}/evidence`，但尚未自动映射为 `run_artifacts`；Run Console 的 Artifact tab 主要展示进程内执行器产物。
5. **Screenshots/Trace 只对 Playwright 生效**；Appium 仍是 UI 层级/点击结果，不含截图，除非后续补。
6. **生产 API 创建 Run 默认关闭**：这是刻意设计，不是缺陷；打开需独立审批与回滚演练。
7. **真实 M2 Dogfood 仍需 Test 环境**：本分支的 1832 条后端测试与 578 条前端测试证明契约和回归，不替代真实 Node/浏览器/DB 的 Run ID 证据。
