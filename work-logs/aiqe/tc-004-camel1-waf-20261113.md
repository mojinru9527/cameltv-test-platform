# TC-004 业务 Web 目标切换为 camel1.tv 的 WAF 实测（2026-11-13）

> 用户指定业务 Web 使用 `https://www.camel1.tv/`。
> 结论：**人工/单次浏览器可访问，但脚本化访问被 WAF 拦截**（403 / ERR_CONNECTION_RESET），
> TC-004（广告浮层交叉干扰）自动化仍无法执行，需白名单或内部 Test 入口。

## 1. 实测序列

| # | 方式 | 结果 |
|---|------|------|
| 1 | `curl`（浏览器 UA）本机 | HTTP 403（TCP/TLS 可达，DNS 156.227.14.33 / 71.18.1.211） |
| 2 | `npx playwright screenshot`（Chromium） | ✅ 成功渲染 Camel Live 首页（截图 572KB，标题/Match 列表正常） |
| 3 | 全局 Playwright `chromium.launch` 无 UA | 打开后标题 `403 Forbidden` |
| 4 | 带浏览器 UA + `--disable-blink-features=AutomationControlled`（headless & headed） | `page.goto: net::ERR_CONNECTION_RESET` |
| 5 | 再次脚本访问 | 持续 reset（疑似按 IP/指纹限流封禁） |

Docker/Test 云主机侧 `curl` 亦为 403；TCP/TLS 可达。

## 2. 判定

| 项 | 判定 |
|----|------|
| 站点是否可达 | ✅ 可达（人工/偶发浏览器成功） |
| 是否允许自动化 | ❌ WAF 拦截脚本化请求（403/reset） |
| TC-004 能否执行 | ❌ BLOCKED（外部反爬，非产品缺陷） |
| 解除条件 | ① WAF 放行测试出口 IP/UA；② 提供内部 Test Web 入口；③ 提供带测试白名单的域名 |

## 3. 影响与建议

- 原计划"用 camel1.tv 替代业务 Web"只能覆盖**人工冒烟**，无法作为 TC-004 的自动化证据；
- 建议优先使用业务 Test 入口（如 `camelive-g3-test5.elelive.cn`，但需内网/白名单），
  或让运维把 AIQE 执行出口 IP 加入 camel1.tv WAF 白名单；
- 白名单就绪后，用 batch-347 的 UI 执行分支跑 Core（无浮层 PASS）/ Integration（注入浮层 FAIL）两条 Run。
