## 2. 流程（同一 Run）

```text
health(HTTP GET aiqe-test-nginx:/api/v1/open/health)
  → ui_forgot(Playwright: 打开 /login → 点击“忘记密码？”→ 断言 /forgot-password + “找回密码”)
    → db_projects(DB-RO: SELECT count(*) FROM sys_project)
      → verify_health(HTTP GET /api/v1/open/health)
```

- HTTP 节点由 Test backend 的 in-process executor 执行（真实 Test Nginx + FastAPI）。
- Playwright 节点由外部 Runner 执行（本机 Chromium，经 SSH tunnel 访问 Test UI），通过
  `execution-jobs/{id}/report` 回写，后端执行断言并落证据。
- DB-RO 节点使用 Test PostgreSQL 的只读角色 `aiqe_ro`（SELECT-only），真实连接 `aiqe-test-postgres`。

## 5. 过程中发现并修复的问题

1. **外部 Runner 无法认领 AIQE Job**：`aiqe_local_runner.py` 的 `CAPABILITIES` 缺少 `api`，
   而后端 `enqueue_node_run` 默认 `kind="api"`，导致 Playwright Job 永远不被认领。
   - 修复：`CAPABILITIES = ["api", "aiqe:http", "aiqe:playwright", "aiqe:appium"]`；
   - 回归测试：`test_aiqe_local_runner_resolver.py::test_local_runner_declares_api_kind`。
2. **Test 前端是旧 Sentinel 静态站**：18080 原本不是 CamelTv 平台，`/login` 无路由匹配。
   - 处理：用当前 main 的 `npm run build` 产物替换 Test 静态目录，`/login` 正常渲染。
3. **SPA 首屏懒加载**：Playwright 立即点击会命中 spinner；工作流增加 `wait_visible` 等待
   `a[href="/forgot-password"]`，再执行真实点击。
4. **Capability Manifest 心跳 30s**：启动前刷新 manifest heartbeat，否则 Preflight 会
   `CAPABILITY_UNAVAILABLE`；Test Dogfood 在 launch 前做了刷新。
