# Batch 270 PRD-lite — 演练驱动改走版本任务流程（让 ⑦ 的复用数字由被验收版本自产）

> **Product/PM** | Date: 2026-09-20 | 档位：**轻量批次**
> `mode: light`
> 豁免理由：改动**只落在验收驱动脚本与其单测**（`scripts/drill_three_versions.py` + `tests/`），不新增平台接口/配置/依赖、不改 Schema 与数据模型、不动执行链路与 AI 链路（平台侧零改动）。判定依据 `docs/agent-team/pipeline-modes.md`：属"内部流程工具 / 验收"档；同口径先例=**Batch 265**（驱动改用用户凭据，同为轻量）。

## 1. 触发

Batch 269 的只读取证（`work-logs/evidence/batch-269/reuse-metric-provenance-20260920.md`）证明：
§5 第 ⑦ 条的 3 版本演练里，驱动**只登记执行任务**（`POST /execution-jobs`）、**不建版本任务**（`POST /version-tasks`），
因此被验收的 3 个版本：

1. **没有版本记录**（`version_task` 无对应行）——而 §5 第 ⑦ 条字面要求"看**版本记录**"；
2. **没有产生任何复用数据**（演练窗口内新增 `reuse_suggestion_event` = 0 条），`hit_rate 0.625` 是**演练前平台既有读数**。

用户要求 ⑦ 必须完成（"1/③/⑦/⑧ 分别都需要完成"），故本批把驱动改成"逐版本走版本任务流程"。

## 2. 本批行为

| # | 行为 | 说明 |
|---|------|------|
| B1 | **逐版本建版本任务** | 每版开始 `POST /version-tasks`（平台据此自动带出上版复用建议并写 `decision='suggested'`），版本记录因此真实存在 |
| B2 | **按本版本增量取数** | `suggested_self = 建任务后计数 − 建任务前计数`；决策后再取一次快照算 `adopted_self / rejected_self` → ⑦ 的分子分母都是**本版本自产** |
| B3 | **逐版本记录人工决策** | 新增 `--decisions-json`：`{版本: {adopted:[标题], rejected:[标题], reason}}`，由操作者按"本版本执行范围是否覆盖该建议条目"判定；未列出的条目保持 pending（**不计入分子**，不用累计数字美化） |
| B4 | **瞬断有界重试**（C269-2） | 仅对**瞬时传输错误**重试；幂等 GET 的 5xx 可重试，**POST 不重试**（避免重复登记）；4xx 与断言失败一律不重试 |
| B5 | **每版增量落盘**（C269-2） | 每完成一版写一次报告文件（`partial: true`），崩溃不再丢 20 分钟全部进度 |
| B6 | **版本号冲突给可操作提示** | 实跑命中：`version_task` 有 `(project_id, version)` 唯一约束，重复版本号时平台返回 **500**（非 409）→ 驱动改为明确提示"请用 `--version-prefix` 换版本系列"（平台侧 500 另登记 `C270-1`） |
| B7 | 保留旧口径 | `--reuse-mode cumulative` 保留旧行为（读平台累计或吃 `--reuse-suggested/--reuse-adopted`），便于对照 |

## 3. 非目标

- ❌ 不改平台代码、Schema、接口、权限（版本号冲突的 500→4xx 语义另登记 `C270-1`）；
- ❌ 不修 `C269-4`（Web `case:605` 断言锚点，P3，本批仍在 29/30 复现，保持 Open）；
- ❌ 不替换人工判断：`adopted/rejected` 必须由操作者给出并写进决策文件（驱动不自动判定"是否复用"）；
- ❌ 不删除既有版本记录来"腾位置"（冲突时换版本系列）。

## 4. 验收判据

| # | 判据 |
|---|------|
| A1 | 3 个版本各自有 `version_task_id`，且每版 `reuse_suggested/adopted` 来自**本版本增量**（`reuse_source=platform:version-task-delta`） |
| A2 | 决策在平台侧真正落到**本版本**的建议 ref 上（`missing=[]`），而不是靠累计计数 |
| A3 | 证据完整率 100%（每版 `evidence_complete=true`），SLO 判定 `meets_all` 由这些**本版本数字**算出 |
| A4 | 瞬断/5xx/4xx 的重试语义有单测（含"POST 不重试"） |
| A5 | 每版落盘（`partial=true`）与版本号冲突的可操作提示有单测 |
| A6 | 既有相关测试不回归（`batch260/261/265/266/268` 各套件） |

## 5. bug-guard 预检

本批只改驱动：新增的出网路径都是**已有平台端点**（版本任务 / 复用决策 / 执行任务），无新增"用户输入 → 出网"面；
版本号冲突的场景本批已实测并给出可读失败（不再裸栈）。风险表核对见 QA 报告三问。
