# Batch 272 PRD-lite — 按角色瘦身导航 + 其余走搜索直达（C271-2 / C259-1）

> **Product/PM** | Date: 2026-09-23 | 档位：**轻量批次**
> `mode: light`
> 豁免理由：**UI/导航展示调整 + 既有命令面板覆盖对账**——不新增接口/配置/依赖，不改 Schema，对外契约不变。判定依据 `docs/agent-team/pipeline-modes.md`（轻量含"UI 调整"）；先例=**Batch 259（B2-6 菜单收敛）同为轻量**。

## 1. 背景（用户裁定）

Batch 271 已把"生产左侧为什么这么多入口"拆成两件事：

1. **数据侧**：13 个已下线菜单仍被角色绑定 → 已按选项 C 清理（残留 0）；
2. **渲染侧**：`专家区` 里仍列着全部模块（tester 13 项），且"当前页落在其中时强制展开"。

用户 2026-09-23 选择 **B：按角色瘦身** ——"tester 只保留 4 个一级 + 少量高频专家项，其余走搜索/命令面板进入"（B 同时是 `C259-1`「被隐藏页面可经搜索直达」的落地路径）。

## 2. 本批做什么

| # | 行为 | 说明 |
|---|------|------|
| B1 | **非超管瘦身**：专家区只渲染 `EXPERT_KEEP_CODES` | 保留 5 个高频资产：用例服务 / 接口测试 / UI 自动化 / 测试数据集 / 目标环境 |
| B2 | **超管不受影响** | `hasPerm('*')` → `slimExpert=false`，仍看资产/引擎与配置/个人/系统全景 |
| B3 | **瘦身 ≠ 下架**：其余菜单进 `searchOnly` | 不渲染、但仍是 `/system/menus` 返回的角色菜单，命令面板（⌘K/Ctrl+K）可搜到并直达 |
| B4 | **可发现性提示** | 专家区标题下方常驻一行「其余 N 个模块已收进搜索：按 Ctrl/⌘ + K 输入名称直达」（**折叠收起时也可见**） |
| B5 | **对账口径** | `导航渲染 + searchOnly = 全部角色菜单`，每个 code 恰好一次（单测断言），并有浏览器实测 19/20 条对账 |

## 3. 非目标

- ❌ 不改超管的导航（管理员仍需系统管理/引擎配置入口）。
