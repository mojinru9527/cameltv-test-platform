## 3. 现有需求全景（用户端）

### 3.1 版本演进概览

```
v1.0    基础框架 MVP：启动 + 登录注册 + 首页框架

v2.2    多端覆盖：PC端 + WEB端 + 个人中心完善 + 资讯
--- 以上为基线存量（对应产品版本 1.0.0~13.2.0）---
v14.0   UGC 重构引入（2026-04-05）
v14.1   首单退币 + 数字货币支付 + 充值赠币 + 人工置顶（2026-05-21，当前测试核心）
```
